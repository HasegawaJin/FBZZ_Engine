# Ragdollの部位操作・バランス観測・つかみ

2026-11-03。汎用APIを先に充実させるユーザー選択に基づく。アニメーション優先モードを維持する。
歩行周期、入力割当、足運び、つかむ物の選択、転倒・起き上がり遷移はC#が所有する。

## 部位操作

骨名は物理定義の完全名。GetBodyName / GetBodyStateで物理部位を列挙・観測する。
SetBodyTargetはWorld / Parent空間の重心姿勢・速度と位置/回転の独立した混合率を受ける。
手動目標の空間をその部位の有効制御空間とし、元のSetBodyDrive設定は保持する。
Parentは最も近い物理親の剛体空間で、物理親が無い根ではWorldとして扱う。
standingGuardは手動目標にも最終姿勢の制限を掛ける。物理主体の制御では明示的に無効化する。
ClearBodyTargetでアニメーション目標へ戻す。出力・周波数・全体Active/Passiveは引き続きSetBodyDrive/SetMuscleが所有する。
力はN・トルクはN·mと継続秒数、力積はN·s / N·m·s。剛体へ直接加え、Transformは書き換えない。
継続力は各substepの予測姿勢へ半陰的な速度・姿勢増分を加え、接触生成前に反映する。

## バランス

重心・質量加重速度・支持点・支持法線・支持面速度・接触凸包に対する余裕を観測する。
自己接触とつかみ拘束を接地支持に数えず、法線が重力の逆方向を向く接触だけを使う。
Contact.Valid は min(contactMargin, 0.001 m) の数値許容内の接触を含む。Penetration=0 は貫通がないことを示し、支持なしとは限らない。離れた予測接点は支持・接触数・休止へ含めない。
重力方向に直交する面へ接触点を投影し凸包を作る。点・線の支持もpadding付きで扱う。
CapturePointはCOMの支持面への投影に水平相対速度×sqrt(COM高さ/重力加速度)を加えた近似。
[Pratt et al., 2006](https://www.cs.cmu.edu/~cga/legs/Pratt_Goswami_Humanoids2006.pdf)の線形倒立振子を参考にする。
可変高さ・大きな全身角運動量・滑りを含む転倒保証ではない。無支持・無重力・高さ不足ではCaptureValid=false。
純managedのバランス補助計算は有限の水平加速度を返す。外力や姿勢目標へ使うかはC#が選ぶ。

## つかみ

部位ごとに独立した点拘束。静的なワールド点とWorldが管理するRigidBodyを対象とする。
[UE Physics Handle](https://dev.epicgames.com/documentation/en-us/unreal-engine/API/Runtime/Engine/UPhysicsHandleComponent)を参考に、位置のみ/回転保持を選べる。
初回に掴み点を両剛体のローカル座標へ保存する。最大到達距離を超えた要求は既存の掴みを変更しない。
陰的ばね減衰を有限出力で位置パスへ反映し、速度導出後に相手へ逆の力積を返す。
World側を再積分・位置射影しない。静止時の速度に重力×substepの見かけの上向き成分を残さない。
回転保持も有限トルク。MaxForceは正、MaxTorqueの0は回転保持を停止する。
BreakForceは上限適用前の要求力を判定し、切断しなければMaxForceで制限する。
破断力0・破断距離0はその破断条件を無効にする。
Release / ForceLimit / DistanceLimit / TargetLostの理由を取得でき、破断を自動再接続しない。
対象の寿命証明を毎回照合し、破棄・コピー/移動・再利用されたアドレスへ反作用を返さない。
把持中の外部剛体と把持元Rigは同じ衝突グループとして相互接触を除外する。
World側を固定姿勢として解く接触反作用と把持が競合すると、小質量物体へ過大な反作用が蓄積するため。
他の物体・床との接触は継続する。静的剛体の支持面は除外しない。
最後の解除・破断・対象差替後、全形状がRigから2cm以上離れてから相互接触を復帰する。
重なった状態で即時に戻すと、貫通解消の反作用で放した物体が飛ぶため。寿命切れの除外記録は破棄する。
Passiveでも掴みは継続する。End / disabled / 非active階層 / Rig再構築で解除する。
Rig再構築では手動目標と継続力も破棄する。Play複製でランタイム操作を引き継がない。
ゲームの範囲・レイキャスト・把持面の選択はこのAPIの呼出元が行う。

## 実操作で見つかった接触の修正と計測

EngineTestControlledMotionMale / Femaleは、両手の目標追従、胴への力積、
片手解除、0.25kgの箱の運搬・落下、足の接地とバランス補助を段階ごとに撮影・計測する。
保持状態のboolだけでなく、位置誤差・物体速度・解除後の落下も表明する。

動的な把持対象とRigの接触反作用が競合し、長い運搬で物体が約85m移動する不具合を再現した。
相互接触を把持中に除外するだけでは、解除直後にも約72〜78m/sで跳ねた。
除外は最後の解除・対象差替後も重なりが解消するまで保持し、静的な支持面は除外しない。
複数部位の保持、静的支持、失敗した差替、重なった解除、分離後の接触復帰を含むnative157件が成功した。

検証用SDKと通常SDK 0.10.0の両方で、男女の実操作各31項目と従来の操作APIシナリオが成功した。
実測は次のとおり。箱のColliderは常時有効で、床・他物体との接触も継続する。

バランス検証は既存の姿勢ドライブを併用し、足の目標を床へ下ろして実接触を作る。
この検証時点の通常立位では足の接触が途切れたため、支持なしを支持ありとして扱わなかった。足裏統合後の通常立位は [足裏接地と速度拘束の統合](active-ragdoll.md#2026-11-03-足裏接地と速度拘束の統合) で別途測定する。
これは自立歩行や補助PDだけでの立位維持の検証ではない。
