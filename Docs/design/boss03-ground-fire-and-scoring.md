# Boss03 の残り火とステージ別採点

2026-09-15。既存の boss03.md / game-flow.md を以下の仕様で更新する。

## 残り火

- Boss03 の槍レーザーだけ、地形に当たった終端へ Fluid ベイク済み JetFlame を置く。空中・壁面には作らない。
- 着火猶予 0.35 秒、燃焼 5 秒、消火 1.6 秒。半径 1.6 m、足元から高さ 1.4 m の範囲で 1 ダメージ、間隔 0.8 秒。地面の炎は弾けない。回避無敵は通常どおり有効。
- プレイヤーのフレーム間移動も判定する。時間と炎はワールドのスローに従う。
- 最大 6 箇所。新しいレーザーを溜めても既存の炎は残す。ボスのダウン・繭・死亡、スクリプト無効化・破棄では消す。

## 採点 version 2

各軸 0〜3 点、合計 9 点。S=8、A=6、B=4。クリアした挑戦を採点する（リトライ前の失敗は次の挑戦へ持ち越さない）。

| ステージ | タイム 3 / 2 / 1 点 | 攻防：各条件達成で 1 点 |
|---|---|---|
| 01 | 4:00 / 5:30 / 7:00 | 最大6連撃・2回弾き・1回完全な拍の締め |
| 02（2体） | 6:00 / 8:00 / 10:00 | 最大8連撃・6回弾き・2回完全な拍の締め |
| 03 | 4:00 / 5:30 / 7:00 | 最大10連撃・4回弾き・2回完全な拍の締め |

被ダメージは共通で 0 / 1 / 3 以下が 3 / 2 / 1 点。攻防は実際に当たった連撃・成功した弾き・完全な拍の締めを使い、空振り入力には加点しない。
タイムは操作可能な戦闘中の非スケール秒。ポーズ・強制演出中は除外する。パリィスローで時計だけ有利にならない。
数値はプレイ調整前の初期基準。旧版記録はクリア・解放を維持し、次のクリアから新版の記録へ移行する。異なる版のタイム・ランクは比較しない。

## 確認

VS で SDK / GreenWare をビルド後、地形着弾と空振り、炎への出入り・高速横断・回避・パリィスロー・ポーズ、ダウン時の消火を確認する。
各 Stage を直接起動して正しい採点表が選ばれること、旧セーブの解放保持、新記録の保存・再読込を確認する。
