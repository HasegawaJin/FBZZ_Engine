# 太陽と島の日当たり

2026-11-05 の日当たり・日の出の見え方の改善依頼に対応する。既存の Sky / SunMoon / DirectionalLight を使い、空だけの独立した太陽方向は追加しない。光源 Transform の forward の反対が太陽方向で、影・水のハイライト・空は同じ方向を読む。

## 円盤と地平線

太陽の角半径は1 AUにおける0.2666度を固定値として使う。軌道計算や時刻・緯度による自動運行は追加しない。[USNOの太陽座標](https://aa.usno.navy.mil/faq/sun_approx)の角半径式を参照する。円盤の縁は正規化した視線と太陽方向の弦長で測り、pixel shaderのfwidthで約1画素の被覆へなだらかに変える。円盤の色は光源のlightColorを使い、夕方の空・直接光と別の固定黄色を重ねない。

地平線はworld Y=0を海面とし、cameraPos.yの非負値を観測高度h、SkyRendererのplanetRadiusを惑星半径Rとして扱う。半径はkmからmへ変換する。幾何学的な伏角のsinはsqrt(h*(2R+h))/(R+h)で、視線yがその負値を下回ると隠す。低い視点での浮動小数点の桁落ちを避けるため、1-(R/(R+h))^2を引き算しない。[SDSUの地平線の伏角](https://aty.sdsu.edu/explain/atmos_refr/dip.html)を参照する。屈折は含めず、実際の海・地形の遮蔽は通常の深度判定を維持する。空コンポーネントが無い場合は6371kmを使う。

地平線の切り替え幅もfwidthから求める。従来のworld方向y=0〜0.003という固定幅は、太陽の大きさや画面の解像度と無関係な帯を作るため使わない。月も円盤の縁と地平線の被覆を共有する。微分を使う関数はpixel shader専用とする。

SunMoonは空と共有するb6へ描画専用の円盤輝度を書き、描画後に元の散乱係数と空の輝度を戻す。後段のAtmosphere Fogがゼロの散乱係数や円盤用輝度を読むことを防ぐ。

LDRのHighlight Compressionは0.55以上の輝度を正規化し、x/(1+a*x*(1-x))で調整する。aは0〜2で、導関数(1+a*x*x)/denom^2が正、黒と白の端点は不変になる。Lumaの比率をRGBへ掛けて色比を保ち、最大輝度の太陽が周囲の空より暗くなる補正を避ける。

## EngineTestProject の晴天

SpruceIslandCinematicの晴天の太陽は高度65度・方位40度へ配置し、林道へ木漏れ日が差し込む向きにする。高度28度では背の高い樹冠が林道全体を覆うため、均一な木陰になっていた。DirectionalLightのfallback値とSkyRendererの昼キーを揃える。shadowStrengthは1とし、遮られた直接光を残して木陰を持ち上げない。FiberのColorパスへIBLのirradiance・prefilter・BRDF LUTを明示的に束縛し、木陰の草は環境光で照らす。物理GIや新しい影方式は追加しない。雨のSequenceにある昼の色・強度キーも同じ晴天値へ戻るよう調整する。

晴天のFroxelFogは海面基準の薄い高度霧とし、近距離で空と海が一様な灰色になる濃度を避ける。強いClarity・低いBloom threshold・過大なGTAOを下げ、日向の葉の色と木陰の階調を残す。PCSSの既存パラメーターを調整し、太陽の影の輪郭が過度に広がる設定を避ける。

## 確認

GPU回帰は本番Atmosphere.hlsliを使い、角直径・海面高度で半分見える円盤・高い視点での地平線低下・完全に沈んだ円盤を検査する。島のPlaytestは林道、海上、日の出を撮影し、エラーログが無いことを確認する。カメラと日の出用の太陽回転は検証中のSceneだけへ適用し、元のシーンファイルへ保存しない。

## 星・月・太陽の描画

`SunMoonRenderer.starBrightness` は既定値0の星の輝度倍率。既存のb6の余白を使い、円盤と星を同じ加算パスへ提出する。太陽高度 −6° から −18° にかけて星を現し、地平線近くは霞で薄める。星の位置はワールド方向を投影した立方体の各面に固定し、画素の角幅で大きさと輝度を調整する。月の被覆分だけ背後の星を減らす。雲は後段の透過合成で天体を隠し、雲の環境光も空の昼夜の明るさに追従する。

月は太陽の反対側に置く既存の配置を使う。月面は球面に投影した海と高地、クレーター、放射状の模様で表現する。`moonSize` は角半径1.5°を基準とした面積倍率。太陽の円盤には周辺減光と局所的な光芒を加え、両天体は地平線に近づくほど暖色へ寄せる。天体はメインビューのHDRへ合成し、空のIBL捕捉には従来どおり大気と雲を使う。

SpruceIslandCinematicはForest Skyの `IslandDayNight.sequence` をPlay開始時に再生する。光源の回転を晴天の初期姿勢から480秒で一周させ、雨のシーケンスは天候を担当する。エディターではSequenceのスクラブで時刻を確認できる。 `IslandCelestial.playtest.json` は昼・夕暮れ・星の有無・曇天・タイムラインで到達した夜を撮影する。
