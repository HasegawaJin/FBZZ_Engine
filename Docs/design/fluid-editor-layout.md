# Fluid Editor のレイアウトとアセット選択

## レイアウト

- Fluid Editor は ImGui の専用 platform viewport を持つ独立した Windows ウィンドウとして開き、メイン Editor のドックには入れない。初回位置はメインウィンドウ中央、以後の位置とサイズは ImGui のレイアウトに保存する。
- OS の閉じるボタンで非表示にし、`.fluid` のダブルクリックまたはパネルを開く操作で再表示する。未保存の文書はパネルの状態に残し、別の `.fluid` を開くときに保存確認を行う。
- 広いパネルでは Outliner、Preview と Timeline、Properties の 3 列を表示する。
- 幅がフォントサイズの 58 倍未満なら Preview / Outliner / Properties のタブへ切り替える。狭いウィンドウでも各設定欄へ到達できることを優先する。
- コンパクト表示へ移ってもユーザーが調整した列幅を変更しない。Timeline の表示高さは中央領域の 55% 以下へ収め、保存する高さはドラッグ時だけ更新する。
- ファイル名は操作ボタンと別行に表示し、ボタンは残り幅に収まらなければ折り返す。長い状態メッセージも折り返す。
- Output の Bake Range はソルバー開始からの Start / End を示す。Start は `output.warmup`、End は `output.warmup + output.duration` に対応し、別のトリミング設定を持たない。Start の数値変更は収録長を維持し、End の数値変更は収録長を変える。Playhead ボタンは現在のコマへ吸着して境界を設定し、開始変更後もプレビューは同じソルバー時刻を指す。
- 部品名の編集欄は Properties 本文に 1 つだけ置く。

## Bake の試作とループ確認

- Draft Bake は編集中のレシピをコピーし、コマ割りを最大 4×4、タイルを最大 128 px、超解像を 1、3D 解像度を最大 64³ に落とす。時間範囲は維持し、結果とレシピは `Library/FluidDraft/` に隔離する。確定版の `.fluid`・アトラス・`.mat`・`.vfx` は更新しない。
- Baked タブの Repeat seam は末尾と先頭から各最大 4 コマを繰り返す。表示したアトラスの各コマから可視面積、輝度、隣接コマの画素差を測り、最後と最初の差が通常の遷移より大きい場合に警告する。警告は判断材料であり Bake を止めない。
- Output の Loop Blend は `.fluid` の `loop_blend_fraction` として保存する。0〜50% の重ね幅を 2D・3D の Bake が共有し、0 は時間的な重ね合わせをしない。既存レシピの既定は 25%。
- Baked タブの Inspect VFX loop は確定 Bake と隣の `.vfx`・`.mat` を一時シーンへ読み、実際の CPU 粒子更新を 30/60 FPS で各 3 周進める。Atlas の可視画素率と粒子の色・大きさ・再生コマを合わせて空白フレームを数え、周期境界の空白も別に示す。確定 Bake の読込時には `.vfx` があれば自動検査し、ボタンで再検査できる。Draft や多層 VFX は対象外。検査で一時シーンを使い、開いているゲームの状態は変更しない。
- 定常開始候補は末尾 1/4 の面積と輝度を基準に、3〜8 コマの移動平均がそれぞれ 20% 以内に収まる最初の時刻を示す。ループの先頭はクロスフェード後の絵なので、先頭から重ね範囲の後まで一貫して安定していない限り、その範囲を候補から除く。人が Use for Bake Start を押した場合だけ Start を動かし、End は維持する。Bake 後に文書の時間範囲が変わっていれば適用ボタンを出さない。
- 工程時間は 2D のソルバーと描画をワーカースレッドで実測し、3D は GPU 処理と CPU 解法が重なるため壁時計時間を状態ごとに配分する。書き出し中など進捗から推定できない残り時間は数値を出さない。

## Mask 選択の寿命

Properties はレシピをコピーして編集し、描画末尾に FluidDocument::Commit へ渡す。AssetPathField のピッカーがこのコピー内の std::string を保持すると、ピッカー表示時点ですでに参照先が破棄されている。

AssetPathField は ImGui ID と現在値のコピーでピッカーを開き、選択結果を次の同一 ID の描画で返す。文字列のポインタをピッカーへ渡さない。1 フレームを超えて呼ばれていない欄の結果は捨てる。Fluid Editor は文書パス・部品種別・部品番号を ID に含め、別の文書や部品へ選択結果を流さない。

独自スロット向け OpenAssetPicker は既存の参照引数の契約を維持する。呼び手は選択完了まで参照先を生存させる必要がある。

## 確認

- AssetPickerTest: コピー破棄後のピッカー描画、選択結果の一度だけの適用、別の欄への誤適用防止、消えた欄への結果破棄。
- VS Code の Build Editor (Debug) と Tests: Build & Run Suite (Debug) でビルド・テストする。
- 実機では Texture 型の発生源へ Mask を選択し、プレビュー反映、Undo / Redo、保存して開き直す操作を確認する。
- 独立した OS ウィンドウとして開き、メイン Editor とは別に移動・リサイズ・閉じて再表示できることを確認する。狭いサイズでも全タブと設定欄に到達できること、再拡大後の列幅、Timeline のリサイズを確認する。
