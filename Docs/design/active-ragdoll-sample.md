# Active Ragdoll の C# サンプル

GameHub の Standard と初期作成される SandboxProject には、
`Assets/Scenes/ActiveRagdollSample.scene` が付属する。プロジェクトの既定シーンは Main のまま。
サンプルは独自の人型モデルと物理定義を持ち、公開 C# API だけを使う。
Animator はバインド姿勢とスキニングに使い、アニメーションクリップは持たない。

| 操作 | 挙動 |
| --- | --- |
| WASD | 前後左右・斜めに歩く。離すと最後の足を接地させる |
| Q / E と WASD | 支持足を置いたまま上体を回し、遊脚を次の向きに着地させる |
| 台に向けて歩く | 地面へのレイで高さを読み、遊脚を先に段へ運ぶ。着地を確認して体重を移す |
| 低い黄色の桟へ歩く | 足先の接触を検出してつまずき、胸が先に前へ出て、反対側の足が支える |
| Space | 両足支持から膝を曲げて踏み切る。空中では重力で落下し、接地後に膝を曲げて戻る |
| ↑、W / S | 箱の近くで手を伸ばして掴み、押す・引く。もう一度 ↑ で離す |
| ← / → | 前／後ろへバランスを崩す。腹側／背中側で床に落ちた姿勢を見て立ち上がる |

落下中も Active のまま駆動を緩め、起き上がりには床の高さ、胸の向き、手足の接地を使う。
身体の移動は部位の物理目標と力積で行う。箱は動的剛体として把持から反作用を受ける。
支持／空中／衝突は物理剛体の観測で判定する。軌跡の補間と着地確認はサンプルが担当する。
サンプルの対象は同梱の人型と練習コース。ゲーム固有の骨格や任意の障害物に対応する場合は足運びと駆動値を調整する。

`Tests/Playtests/ActiveRagdollSample*.playtest.json` の8件で固定 60 Hz で確認する。
シーンを開いた状態で、動作ごとに実際の入力を送り、接地、変位、姿勢、箱の移動、復帰を物理の観測値で表明する。
