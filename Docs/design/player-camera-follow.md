# Playerの画面内移動とカメラ追従

2026-09-13。既存のTpsCameraとCameraFollowManagerの追従を拡張する。

- Playerの移動に対して注視点を指数補間する。既定の時定数は0.18秒で、停止後約0.54秒でずれの95%を解消する。
- カメラの向きと注視点からの旋回軌道は入力へ即応させる。最終カメラ位置を補間して視点操作まで遅らせない。
- 回避・跳躍のFollow Slack要求は軸別の時定数を伸ばす。ずれは既存のmaxSlackOffsetで制限する。
- 初回・対象再取得・20m以上の位置差は注視点を捕獲し直す。演出からのResumeFromでは現在の画から注視点を復元する。
- 揺れは追従状態へ戻さず、実時間で追従する。編集時は追加の遅れを使用しない。
- PlayerのRagdollは無効化する。移動・被弾・撃破による上半身への衝撃を撤去し、撃破後の移動停止と結果画面への進行を維持する。

ビルドと実機検証はVS Codeで行う。横移動、切り返し、回避、跳躍、視点旋回、演出復帰、撃破を確認する。
