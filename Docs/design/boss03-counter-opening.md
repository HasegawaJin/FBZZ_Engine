# Boss03：羽の反射・落下・本体への反撃

2026-09-15。boss03.md / parry-rush.md を今回の依頼で更新する。

- パリィ後のTPSはプレイヤーと相手の間へ注視点を少し寄せ、距離を広げる。強制カットやロールを使わず、手動の視点入力を優先する。ポーズでは補間も止める。
- 羽の反射は帰還経路で本体へ命中したときだけ成功とする。高速移動の線分も判定し、時間切れの帰還ではダウン報酬を出さない。
- 反射命中で本体へ80ダメージ、攻撃を中断して地形まで落下。着地後6秒間は反撃可能。着地時にパリィラッシュを開始し、接近と落下演出で連撃時間を使い切らない。
- ダウン中の部位とどめで即座に起こさない。1ダウンに1枚だけ切断でき、残り時間は本体を攻撃できる。回復は0.8秒の浮上を挟む。
- 本体はBodyボーンのヒットボックスからHPへ転送する。とどめの部位候補にはしない。上空の本体を水平距離だけで斬らない。
- 本体HP1400、通常本体ダメージ×0.35、ダウン時×1.25。通常斬撃25、ラッシュ連撃・追加ヒットを含め、反撃2〜3回程度を初期目安とする。実機調整前の仮値。
- 装着翼240、投擲翼160。翼破壊は最大本体HPの10%を削る。6枚破壊による決着も維持。HP半分または翼3枚以下で第二段階へ移る。

## 反撃の手応え（2026-09-15追記）

- 着地時にパリィ用のカメラ構図を更新し、短い画角の広がりで接地を強調する。ラッシュ開始は着地後のまま維持。
- ダウンした本体の発光を弱点ヒットと同じ金色にする。通常時の翼・本体の予兆は維持する。
- 攻撃補助は視線前方かつ捕捉範囲内のダウンした本体を優先する。無敵の本体には吸い付かない。
- 踏み込みは減衰する速度の積分に合わせて初速を補正する。既存の速度上限・衝突処理は維持する。
- ラッシュの通常段はヒットストップ強度を0.28以下に抑え、締め・部位破壊で強弱を付ける。

## 確認

VSからGreenWareとTestsをビルド。反射の高速命中・空振り帰還・死亡中の帰還、落下と地面への接地、とどめ後の反撃継続、HP撃破、手動カメラ操作・ポーズ・復帰を確認する。
