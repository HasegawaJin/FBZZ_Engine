# CPU 遮蔽カリング

## 描画深度を使う GPU Hi-Z

DX12 の間接描画または Mesh Shader モードで、遮蔽カリングと GPU インスタンス選別が有効なビューを対象とする。`TerrainHiZInstances` が不透明パスと同じビューの地形パスの後に実行される場合だけ、色の `InstanceSet` をその位置へ移す。Deferred では GBuffer の深度を HDR へ転写する前、Forward では HDR に地形を書いた後に行う。元のパスが無効、グラフから除外、またはビューに候補がない場合は従来の順序を使う。

階層は描画先の深度 SRV を読み、4×4 ピクセルから始めて各軸を切り上げながら 2×2 ずつ最遠値を集約する。Reversed-Z のビューは最小値を使い、未描画のセルの 0 を保持する。候補をジッター込みの同じ射影で包み、投影矩形を覆うすべてのセルより手前に来ないことを確定できた候補だけを GPU 上で省く。近面や画面境界に触れる候補、深度バイアスのある材質、無効な深度・境界は既存の可視性判定へ戻す。地形の穴・選択 LOD・材質の被覆は実深度に従う。

この経路では CPU の地形深度生成を省き、色・影の地形に既存の GPU LOD 選択を使える。GPU 階層が利用できない場合は CPU のメッシュ遮蔽と既存のインスタンス経路を使い、地形遮蔽を証明できなかった候補を残す。ビュー・スナップショット・資源の世代が変わった階層は無効とする。影、選択、速度、反射キャプチャのインスタンスはそれぞれの既存経路を使う。CPU 描画モードと非対応バックエンドでは従来の地形遮蔽を使う。

カメラごとに任意で有効化する。既定は無効。各ビューで深度を初期化し、そのビューの描画と同じ TAA ジッターを使う。過去フレームの可視判定は再利用しない。

`RenderPipeline::Execute` が override と RenderGraph の除外を解決した後、実行順に残る色・深度パスだけを遮蔽物の登録元にする。Forward の DepthNormalPrepass だけでは主画面の遮蔽物と認めず、Deferred の登録には GBuffer と HDR 深度コピーの両方を要求する。準備後に snapshot、カメラ、射影、ジッター、レイヤー、描画距離、パス設定や資源世代が変わった場合は CPU/GPU とも古い遮蔽を使わない。

## 外接球と内接球

描画候補の検査は、現在姿勢・葉の風変位・カメラの余白を含む外接球を使う。透視投影では `radius / depth` だけで検査領域を作らず、球を包むビュー空間の箱の 8 頂点を投影する。near 平面をまたぐ球、未確定・非有限の境界は描画する。

遮蔽者には同じ中心の内接球を使う。`Mesh::ComputeBounds` と `ComputeBoundsExtents` は、CPU の三角形位置を完全一致で溶接し、全辺が逆向きに 2 回現れること、全三角形が中心を一貫した向きで囲むことを確認する。中心から最寄りの面平面までの距離から数値余白を引いた球を保存する。面欠落、不正 index、縮退、非有限、スキン・モーフ、6,144 index を超える入力は証明せず半径 0 とする。CPU 証明はメッシュ境界を更新する時だけ行う。

ワールド内接球は TRS 行列の最小軸スケールを掛ける。外接球の最大軸スケールやカメラ余白は使わない。カメラが外接球内にある場合も遮蔽者として登録しない。

## 被覆と深度

標準の頂点・被覆契約、不透明 Blend、alpha cutoff 無効、風無効、LOD dither 無効、深度 bias 無効、塗りつぶし描画だけを登録する。材質やシェーダーの契約が不明なら登録しない。

内接球の中心深度にある円盤は実形状内部にある。その投影に内接する正方形で、低解像度セル全体が覆われる範囲だけを書き込む。深度は実表面の出口より遠い外接球の背面とし、遠方へ丸める。検査対象は外接領域と重なる全セルについて、その最近点より既存深度が手前にある場合だけ棄却する。

[Microsoft の conservative rasterization 定義](https://learn.microsoft.com/en-us/windows/win32/direct3d11/conservative-rasterization) の underestimated coverage と同様に、遮蔽者の被覆を広げない。[PBRT の境界契約](https://www.pbr-book.org/4ed/Shapes/Basic_Shape_Interface) と同様に、検査対象の境界は表面全体を包む。

## 関連する境界と統計

地形は実描画と同じ LOD の CPU 高さ・index から、実際に描ける三角形だけを登録する。穴、未準備の VB/IB、不一致の個数や不正なグリッドは遮蔽物にしない。三角形・凸四角形は表向きでセル全体を覆う領域だけを書き込み、最遠頂点より遠い深度を使う。処理予算を超えた形状は登録を省略する。

通常 mesh、InstanceSet、Fiber、Particle、Terrain、Water、Trail、Decal の可視判定は同じビューの遮蔽を参照する。影にはカメラの遮蔽深度を流用しない。GPU InstanceSet へ渡す深度行も、同じ snapshot とビューが有効な場合だけ使う。

スキンメッシュの影は現在姿勢のオブジェクト境界で判定し、バインド姿勢の submesh 球で再棄却しない。葉の変位は通常 static/skinned と InstanceSet のいずれにも含め、材質変更を空間索引・複数ビューのキャッシュへ反映する。

InstanceSet の CPU 除外は個体ごとに 1 回集計する。GPU 判定で読み戻していない個体数は未確定として別に示す。可視数の完全性は [InstancedMesh の設計](instanced-mesh.md) に従う。

## 回帰検証

`MeshOcclusionTest` と `OcclusionCullerTest` は閉メッシュの証明、立方体の横の可視保持、中央の実遮蔽、透視・正投影、余白・near・不正入力・ビュー初期化を CPU で検証する。描画パスの fake backend 回帰は材質・LOD の被覆判定と現在姿勢の影提出を確認する。実 DX12 の InstanceSet 回帰は CPU/GPU 経路の画素と統計を確認する。

## 地形・植生・水面の共通判定（2026-11-07）

連続した高さ場は、重なる矩形範囲の最低標高から作った列を遮蔽者に使う。列は地形より上へ出さず、最低標高からさらに 1 cm 下げる。全タイルが正方格子・平行移動のみで、穴がなく、矩形領域を重複なく埋め、タイル外周とチャンク内側の共有辺の高さが一致する場合だけこの経路を使う。near 面が実表面より上にあることを、near の footprint 内の現在 LOD の三角形で確認する。領域外のカメラは全地形より高い場合だけ認め、列の下端を視線の領域進入条件で切る。この進入条件は透視投影だけで使い、正投影は通常の kernel・実三角形へ戻す。地下・near 交差・不連続な地形で列を壁として扱わない。

高さ場の形状証明と列は不変の CPU 形状・行列・資源世代に対して再利用する。cache hit の前にも現在選択した LOD の VB/IB 生存・正の描画個数・CPU index 個数との一致を確認する。key は抽出された地形集合と全 LOD の形状・資源世代を含み、ビューだけで変わる選択 LOD や生の layer mask は含めない。全 LOD をまとめて証明するため、これらを含めると異なるビューの往復だけで同じ証明を再構築してしまう。全 height が有限で、各 LOD の整数 XZ 三角形が正向きであり、内辺が逆向きに 2 回だけ現れ、単独辺が矩形外周だけにあり、面積和が格子矩形と一致することを証明する。LOD0 は near のセル直接参照に使うため、標準の row-major 2 面/セルの index 順序も確認する。個数だけで穴なしとは判断しない。カメラの可視結果や過去の深度は再利用しない。通常のチャンクでは 16 セルごとの列に 4 セルの重なりを持たせ、現在 LOD が使う表面の下限を地形編集時に計算する。色・影は引き続き同じ CPU 地形 LOD を使う。一般形状・証明できない topology・穴のある地形には、以下の実三角形の保守的な経路を残す。

cache hit では保持済みの形状所有者と入力を照合し、共有参照の取得・解放を繰り返さない。新しい形状の強参照は証明を更新する時に取得する。地形を含まないビューのために、別ビューが使う証明を破棄しない。

CPU 地形の遮蔽証明に native buffer pointer は不要。VB/IB の生存確認は世代付きの `GetBufferMetadata` 台帳を使い、全パッチで `Get` による CPU 描画待機を繰り返さない。InstanceSet の CPU 選別ループも資源更新・callback を呼ばない範囲で、ビューの完全な照合を source ごとの入口にまとめる。

通常メッシュも、色パス・不透明被覆・内接球・視錐台と距離の条件を満たす候補だけ native VB/IB と shader を解決する。これらの条件で除外される物体には、`Get` に伴う CPU 描画待機を発生させない。実際に遮蔽物として登録する直前の資源生存確認は維持する。native 資源の解決中に callback が遮蔽器を交換・再初期化した場合は、準備の入口で捕捉した遮蔽器と Reset 世代を照合して登録を止める。

地形の列には不変の二分木を作り、節の外接箱が画面外・遮蔽済みなら子をまとめて省く。箱そのものを遮蔽者に使わず、葉に残る証明済みの列だけを描く。凸面の低解像度被覆は半平面から行ごとの区間を求め、両端のセル全体の被覆を再確認して書き込む。大きい列で各セルの全辺を検査し直さない。

葉の列は、実表面の内側にあることが証明された箱だけを `RasterBox` へ渡す。箱の遮蔽検査では 4 頂点ずつ同じ演算順で投影し、その結果を各面で共有する。画面内の頂点を含むセルが、その頂点の深度閾値に達していれば箱は可視と確定する。箱全体の最近深度から求める閾値は、頂点の閾値以下だからである。列を描くときは残った面に必要な頂点だけを投影する。標準射影の球でも、遮蔽物の登録を伴わない検査では頂点を含む未記録のセルで可視と確定する。near 交差・不正頂点の面は有効な元の三角形だけを使う。

箱や面の投影矩形に完全なセルが入らなければ、面の分割と被覆計算を省く。行の被覆では半平面の境界を左右で集約し、セル番号への丸めを各端で一度だけ行う。矩形の深度検査は double の閾値以上で最小の float を求め、既存の float 深度セルをまとめて比較する。元の double 比較と同じ境界を保つ。

標準の透視投影では、列の外向き面に対する眼点の位置から確実な裏面を投影前に省く。Camera と float view 行列から戻した眼点の両方、および列の座標丸めを含む外向き区間で判定する。境界に近く判別できない面は残し、一般射影・非有限・非標準の view は従来どおり全 6 面を登録する。面の順序・頂点・低解像度被覆と深度の式は変えない。回帰は面の境界と隣接 float、左右と後方の斜視、4,096 m の原点移動、TAA ジッターを含む 108 条件で、6 面を登録する基準の全深度セルとビット一致を要求する。

実行計画の確定後、各ビューで `PrepareViewOcclusion` を一度実行する。深度は 256 × 144 の線形 view-Z。無効なパスの形状、別カメラ、過去フレームの深度は使わない。通常メッシュ・スキン・半透明、InstancedMesh、Fiber の色・速度、地形、水面、粒子・デカール・軌跡の描画候補は同じビューの情報を検査する。編集の選択輪郭と透過マスクの非可視指定は表示契約を保つ。影は光源錐台で判定し、主カメラの遮蔽結果を使わない。

地形は GPU へ提出するものと同じ頂点高さ・穴・境界接続の index を CPU キャッシュへ保持する。境界未確定・65535 頂点超のパッチは遮蔽者に登録しない。現在の描画 LOD の表面だけを登録し、裏面・near 交差・縮退面は捨てる。隣接 2 面の凸投影は共有対角線の穴を作らず結合し、凹投影では元の 2 面へ戻す。セル全体が面内に収まる領域だけに、頂点の最遠深度を遠方へ丸めて書く。処理上限はビューあたり 10 万三角形で、超過時は遮蔽不足へ倒す。GPU の地形 LOD と表面の証明がずれないよう、遮蔽有効時は色・影とも既存の CPU 地形 LOD を使う。

現在 LOD の topology に同じ矩形の完全被覆を証明でき、全三角形が正面を向くパッチでは、境界の内側半平面の共通部分から内接矩形を取り、全頂点より遠い view-Z の被覆として登録する。これにより内部 tessellation のセル境界が穴にならない。非有限の height、穴・重複・反転・未証明の辺接続、裏面の混在、狭い kernel は実三角形へ戻す。far の NDC 深度の逆変換は桁落ちするため、既知の view-Z と投影行列から矩形頂点を直接解く。現在 LOD に必要な頂点だけを投影し、作業領域の容量を再利用する。

InstancedMesh の CPU 選択と GPU 間接描画は、外接球を包む 8 頂点の投影を検査する。同じ CPU 深度を t30 の構造化バッファへ一度だけ転送し、GPU の可視 ID・間接引数を GPU 上で絞る。読み戻しを追加しない。GPU の丸め余白は外接投影を広げ、最近深度を手前へ寄せる。GPU 結果の統計は従来どおり未確定候補として表示する。

CPU の空間選別が返す可視 ID は LOD ごとに元の個体順へ戻す。密な結果は再利用ビット列から昇順に取り出し、疎な結果は従来のソートを使う。選別条件・LOD・提出順を変えず、可視個体が多いときの並べ替えを軽くする。

海・河川・湖は通常パッチ、可変 LOD パッチ、遠景海面の全経路で AABB を検査する。外接球は平たい水面を上下へ過度に広げるため使わない。波・水平移動・morph の境界とカメラ余白を含め、near 交差やカメラを含む境界は描画する。別カメラの水面捕捉に主ビューの遮蔽を流用しない。

Fiber は抽出済みの風・長さ・接触変形を含む境界を使い、Shell・Fin・Hybrid・Blade 共通で判定する。粒子は既存の発生範囲・移動・履歴の保守的境界を渡し、遮蔽で描画を省いても GPU シミュレーションは止めない。軌跡は平滑化とマイター処理後の実頂点、静的メッシュ残像は保存した過去姿勢の境界を使う。変形境界が未確定な残像や独自頂点変形は半径 0 とし、安全側へ描画を継続する。
