# GreenWare 全ボスの攻防調整

2026-09-15。既存の `GreenWare/Assets/Docs/boss.md`、`boss-serpent.md`、
`boss03.md`、`break-parry.md` を基礎とする現行実装の補足。

## 守る体験

予兆どおりに防げること、防いだ後に反撃が届くこと、部位破壊で戦いが進むことを優先する。
攻撃テンポと、プレイヤーが獲得したとどめの猶予は別の時計にする。
テンポを上げても猶予はゲーム時間の秒数を保ち、HUD と一致させる。

## 今回の変更

- 共通：転倒中・獲得倍率ゼロの入力で熱や連続弾きを蓄積しない。
  減衰開始の境界をまたぐフレームでは、境界より後の時間だけ減衰させる。
- 共通：減衰の時計を停止できるようにする。直近の獲得時刻を使う HUD の時計は進める。
- Boss01：登場などのカメラ拘束中は減衰を止める。踏みつけの解決中に崩れたら
  元の攻撃処理へ戻らない。命中済みの踏みつけの予兆を消し、突進の帯は実際の突進方向を使う。
- Boss01：転倒時間を攻撃テンポで短縮しない。
- Boss02：噛みつきの接触結果によらず振り切った後の硬直を残す。
  薙ぎ・叩きつけの硬直中は反動が終わっても巡航を再開しない。
  叩きつけの解決中に崩れたら攻撃処理を中止する。休眠・開口待ち・潜行・死亡中は減衰を止める。
- Boss03：各拍の翼投げを維持し、通常の拍は通常ダメージ、締めは締めのダメージとする。
  古い文書の「締めだけ翼投げ」は現行の仕様ではない。
- Boss03：連撃後の硬直中は水平移動を止める。弾き・ジャスト回避からの崩しを
  元の攻撃処理で上書きしない。転倒時間をテンポで短縮しない。
- Boss03：登場・繭・休眠・死亡中は減衰を止める。
- Boss03：床と跳躍判定の基準を浮遊アニメーションから切り離す。
- Boss03：翼は前フレームから現在までの線分と胸位置で接触を判定する。
  高速時の当たり抜けと、高さを無視した被弾を防ぐ。
- Boss03：崩し・繭入りで飛行中の翼を落とす。撃破時は翼の攻撃・物理・コールバックを停止し、
  どの撃破経路でも遠隔攻撃の停止と撃破演出を実行する。帰還時間切れには弾き返しダメージを出さない。

## 追加調整：脚への照準と Boss03 の翼

- Boss01：届く脚を優先して選び、振り出しに狙いを固定する。体と刃の向きを合わせ、脚が選べない場合の胴中心への吸着を止める。
- Boss03：投げる翼を予兆開始時に決め、左右の動作と一致させる。予兆の確定後は移動を止める。
- 出払った翼を連撃数に数えない。最後の飛行攻撃が終わってから、テンポ倍率で短縮しない反撃時間を確保する。
- 部位から本体を引く経路を共通化し、分離した翼にも持ち主を設定する。転倒時の落下翼にもとどめが通る。
- 落下翼への削りは再投擲でも保持し、回収予兆中も破壊できる。破壊済みの翼を遅れて届いた帰還通知で復活させない。

追加の実機確認：四脚の間と外周から手前の脚を斬る／攻撃中に狙いが別の脚へ飛ばない／翼を削って回収させ再投擲後の耐久を確認／回収直前の破壊／全翼投擲中の転倒と落下翼へのとどめ。

## 検証

`Projects/Tests/GreenWare/Auto/BossBreakTests.cpp` に5件の回帰テストを追加。
獲得禁止時のボーナス、減衰境界、長い演出中の保持、転倒の一度だけの通知と再開を確認する。

ビルドとテスト実行は VS Code / Visual Studio のタスクから行う。
この変更時点ではコンパイル・自動テスト実行・実機の手触り確認は未実施。

### 実機での確認項目

1. Boss01：崩しが満ちる踏みつけを弾き、予兆が消えてとどめが通ること。
   脚欠損でテンポが上がっても残り時間のバーと起き上がりが合うこと。
2. Boss02：噛みつきを回避・ガードした後にも頭を斬れること。
   薙ぎを弾いた後に胴が巡航で逃げないこと。潜行をまたいで崩しが維持されること。
3. Boss03：通常の翼投げと締めの被害・崩し獲得量を確認する。
   連撃後に本体へ近づけること。低いフレームレートでも翼がすり抜けず、高い位置を飛ぶ翼に地上で被弾しないこと。
4. Boss03：翼が飛行中に崩す・繭へ移る・倒す。とどめ中と撃破後に翼から被弾しないこと。
   最後の翼を落下翼の破壊ととどめの両方で倒し、攻撃が消えてリザルトへ進むこと。
5. 3体とも、序盤・部位半減・最後の部位で反撃が届く距離と攻防回数を記録し、
   演出量・拍の長さ・撃破所要時間の最終調整に使う。
