# シェーダー再読み込みと描画キャッシュの寿命

2026-09-15。DX12 の SDK 更新後の描画破損と Standalone UI の調査に伴う対策。

## 差し替えの契約

- ResourceManager は全候補を生成してから差し替える。1 件でも生成に失敗した場合は旧状態を保持する。
- 差し替え前に IRenderer の境界を通して GPU の完了とバックエンドのキャッシュ無効化を要求する。
- DX12 は記録中のフレームでは要求を拒否する。未提出のコマンドは GPU 待機だけでは保護できない。
- Graphics / Compute PSO は DX12Shader のアドレスをキーにしている。旧シェーダーを破棄する前に両キャッシュを空にし、アドレス再利用による誤一致を防ぐ。
- Root Signature は維持する。描画状態の差分キャッシュは無効にし、次の描画で再束縛する。
- 成功時だけシェーダー版数を進める。ResourceHandle とデバイスリセット版数は変えない。
- UI のマテリアルキャッシュはシェーダー版数も監視し、定数バッファの配置情報と GPU バッファを再構築する。
- Material の再確保判定は CPU 配列長ではなく GPU バッファの容量を使う。呼び出し側が先に配列を新レイアウトへ更新しても、旧容量の GPU バッファを再利用しない。

## Editor の HLSL ソース監視

HLSL/HLSLI と compile_shaders.ps1 のパス・更新時刻・サイズによる指紋を比較し、追加・更新・削除・改名を検出する。compiled / compiled_dx12 と CSO / meta は対象から除外する。

起動時の確認以降は、読み取り専用の走査を TaskSystem の共有プールへ最大 1 件だけ投入する。main thread は待機時間 0 の完了確認と結果の適用だけを行い、定期的なツリー列挙やファイル属性取得で描画を止めない。完了後から次の走査まで 0.5 秒置き、変更時の 500 ms debounce と再コンパイル・差し替えの既存経路を維持する。

worker は監視ルートのコピーだけを所有し、Editor、Scene、コンパイラー、描画リソースに触れない。監視先の再初期化では旧 future を捨て、旧ルートの結果を新しいプロジェクトへ適用しない。共有プールが終了時に worker を回収する。プロファイラの HotReload::PollHlsl は main thread の受付・完了確認だけを計測する。

## Standalone の入力初期化

Standalone はウィンドウとレンダラーの設定を得るため、Application::Init より先に ProjectSettings を読む。
そこで読み込んだ Input.inputactions を初期化で LoadDefaults に戻すと、Submit / Cancel と独自アクションが失われる。
InputActionMap::Initialize は未設定時だけ既定値を作る。明示的な Clear や空ファイルの読み込みも設定済みとして保持する。

## 動的 UI 頂点の寿命

DX12Buffer::Update が永続 Map 領域を直接上書きすると、前フレームの GPU 描画と競合する。
StageSelect のリッチテキストは毎フレーム頂点の色や文字列を更新するため、この経路を通る。
更新されたバッファは CPU 側へ値を保持し、Submit 時にフェンスで保護された UploadArena へ複製する。
同一フレームの未変更データは再利用し、Update 後またはフレーム変更後には別領域を使う。
更新しないメッシュと GPU スキニングの出力は従来のリソースをそのまま参照する。

## 実機確認

VS Code / Visual Studio で Editor と SDK をビルドして再起動する。DX12 で Scene / Game を表示しながらシェーダーを複数回再読み込みし、描画と UI の材質が維持されることを確認する。
コンパイル失敗時には旧描画が残り、修復後に再読み込みできることを確認する。
Standalone UI の欠落は同一原因と断定せず、対象シーン・ログと配布アセットを別途照合する。

StageSelect で文字の出現・色変化を確認し、マウスとキーボード・ゲームパッドの決定 / 戻るを確認する。
起動時に読み込んだ入力設定の保持と空設定の保持を InputActionMapTests に追加した。
ShaderReloadTests は一括失敗・安全な差し替え順・レンダラーの拒否・パス区切り・GPU 定数容量を検証する。
