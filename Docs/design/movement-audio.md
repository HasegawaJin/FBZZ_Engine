# Player・Bossの移動SE

Playerの移動は連続モーターを採用。歩行・走行の単発音と走行停止音を置き換え、Stage_01の先読みへ登録する。

2026-09-14。Playerは高性能ロボットの滑らかなモーター加速・制動、四足Bossは荷重移動、蛇は擦れと通過で区別する。
正本は `Tools/SfxGen/gen_movement.py`。最終構成は36本。既存30本を更新、新規6本。不要になった歩行・走行14本と停止2本はmetaごと削除する。
すべて手続き合成、48kHz / 16bit PCM / mono。既存の戦闘SEと同じ書き出し処理を使う。

| 対象 | 素材 | 本数 |
|---|---|---:|
| Player | 回避3、回避終了1、着地2、旋回3、登攀3 | 12 |
| Player追加 | 踏み切り2、連続モーター1 | 3 |
| 四足Boss | 歩行周期4、高速周期4、サーボ1、突進予備1、突進ループ1、激突1、スタン1、復帰1、登場1 | 15 |

## 再生

- 移動の実速度をMoveSpeedで正規化し、専用の2D LoopVoiceで再生する。歩行・走行の歩ごとの再生は廃止。歩幅計算は走行VFXのために残す。
- 1秒ループはチャージ波形を4倍速にした基音440Hz。速度によりpitchを0.95～1.35、gainを0.35～0.75へ滑らかに変える。
- gainは立ち上がり0.08秒、停止は最大0.30秒の線形変化。pitchは時定数0.10秒で追従し、停止時0.85へ下がる。減衰中の再加速では再生位置を保つ。
- 空中・操作保持中は減衰し、無効化・破棄・必要コンポーネント不在では停止する。攻撃や被弾の音量・pitchには影響しない。
- 回避・踏み切り・着地・旋回・登攀は短い動作音を残し、移動の連続音に重ねる。
- 踏み切りは固定ステップで実際に跳んだときだけ予約し、可変フレーム側で一度鳴らす。
- 四足Bossの歩行WAVは40/30秒、高速歩行は1秒。それぞれ4接地を含む1周期。再生コード側でさらに4回鳴らさない。
- 突進ループは2/3秒・4接地。既存の単発歩行抑制を維持する。
- 蛇は頭の速度で音量を駆動し、Rush中だけ専用ループへ切り替える。四足の突進ワンショットは重ねない。
- 大ジャンプ着地は専用バンク。踏みつけImpactとSettleの二重再生はこの経路では行わない。
- 音源の存在を示すサーボ・匍匐は控えめにし、攻撃予兆の音量領域を空ける。

## 生成と整理

```text
python Tools/SfxGen/gen_movement.py --output GreenWare/Assets/Sound/SE --preview <directory>
```

同じseedでPCMは再現する。既存WAVのmetaは書き換えず、新規ファイルにのみGUIDを発行する。
旧WAVの退避コピーは作らない。旧登攀生成処理を `gen_hatch_climb.py` から取り除き、同ファイルはハッチ開閉だけを生成する。
戦闘SE生成器のwriteにループ指定を追加した。名前にLoopがないCharge_Runも、端点の強制消音とディザを通さず周期を保つ。

## 検証範囲

36本の形式・再現性・非クリップ・DC・無音端点、ループの境界差、GUID保持とカタログ参照を確認する。
デモは歩行・走行などを合成した試聴用シーケンスで実機録音ではない。デモごとのピーク正規化はせず相対音量を保持する。
ビルドとゲーム内での聴感・距離減衰・アニメ接地との位相はVS Code / Visual Studioで確認する。
