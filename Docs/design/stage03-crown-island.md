## 造形

Stage01 の灰色装甲・黒い機械関節・赤い横長の単眼を引き継ぐ。中央の胴体を左右三枚ずつ、計六枚の盾状装甲翼が囲む。開いた姿は王冠、閉じた姿は縦長の繭。人型の手足は付けず、低空を浮遊する。

本体・赤い単眼・下部の弱点コア・六枚の翼・根元の関節を編集可能な部品に分ける。翼は個別に可動・脱落できる。前方は Blender の -Y、上方は +Z、単位はメートル。原本は `GreenWare/Assets/_src/Boss03/Boss03.blend`。

## Blender でのモーション確認

ユーザー指定の N サイドバー `Boss03` からモーションを選択・再生する。待機・移動、展開・攻撃、被弾・撃破、翼の脱落、デモに分類する。選択時はリグの Action と適合するスロットを切り替え、フレーム範囲を当該クリップへ合わせる。再生・停止・ループ・攻撃タイミングへのフレーム移動、六翼 / 四翼 / 二翼の表示切り替えを提供する。

確認用 Python は .blend 内と同じフォルダーに同梱する。既存のスクリプト自動実行設定は変更しない。`Open_Boss03.cmd` から明示的にプレビュースクリプトを読み込んで起動できる。25 本のクリップを収録し、水平移動・当たり判定・発光やレーザーは引き続きゲーム側の担当とする。

## 戦闘

攻撃の予兆を読み、攻撃後に露出する翼の関節を破壊し、落下した本体のコアを攻撃する。六翼から四翼、二翼へ段階的に進む。二枚破壊するたびに姿勢を崩し、最後の二枚ではコアを常時露出する。壊れた翼は復活しない。コア HP が尽きると撃破。

| 攻撃 | 予兆と動き | 反撃機会 |
|---|---|---|
| 叩きつけ | 使用する翼が発光し、振り上げて地面へ刺す | 地面から引き抜くまで関節を狙える |
| 扇状レーザー | 三枚の翼を前へ向け、床に照射線を予告する | 安全地帯へ移動し、照射後に接近する |
| 繭突進 | 翼を閉じて直線移動する | 横へ回避し、陸上で停止して展開する隙を狙う |

普段の高度とダウン時のコア位置は、プレイヤーの近接攻撃が届くよう実機で調整する。HP、予兆時間、ダウン時間は未調整。Blender の攻撃クリップは動きの素材であり、当たり判定・ダメージ・AI は別途実装する。

## マップ

青灰色の海にそびえる岩の孤島。小さな入り江から岩壁沿いの登り道を進み、頂上の円形闘技場に到達する。途中から中央台座上の繭が見える。

闘技場は仮寸法で直径 45〜55m。中央は平らに保ち、周縁だけに岩と壊れた柱を置く。中央から六方向に金属の溝が伸び、起動時に赤く光る。低い岩の縁で落下を防ぐ。初期版に足場崩壊は入れない。

登場時は海と空を背に翼を展開する。崖外へ出る突進演出の終了地点は必ず陸上。脱落翼は戦闘を妨げず海へ落ちる。ボスの制作と、マップ・既存ゲームへの組み込みは別の工程として検証する。
