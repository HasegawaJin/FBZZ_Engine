# 川の自然ルール

`terrain.river.validate` は Edit Scene の `Spline River` 1 本を検査する Query。Water Inspector と `editor_op_query` は同じ操作を使う。AI 制作では編集上の配置案を保存する前に検査し、違反があれば既存の地形・制御点操作で調整して再検査する。しきい値は呼び出しごとに指定する。標高そのものに上限は設けない。

現在の Inline または TargetPoint の制御点から既存 Water スプラインを構築する。波・Water Zone の接続補間前の水面を測る。川の横断面の中点に加え、横断面間を `sampleSpacing` m（既定 2 m）以下で測る。埋没と川床は中心線で判定する。岸の検査を有効にした場合は別に左右を測る。長い川で標本上限に達したら、間隔を広げるか区間を分ける。

| 検査 | 判定 |
|---|---|
| 流向 | 正の流速は点順、負の流速は逆順。すべてゼロなら点順。正負が混在する場合は違反。 |
| 逆勾配 | 上流からその地点までの最低水面高に対して、`maxUphillRise` m（既定 0.1 m）を超えて上がった地点を返す。 |
| 急な落差 | 下流へ向かう水面の落差が、水平距離に対して `maxDownhillGrade` m/m（既定 0.25）を超える。 |
| 川幅・水深の急変 | 隣接標本間でのワールド川幅または水深の変化量が、水平距離に対して `maxWidthChangeRate` / `maxDepthChangeRate` m/m（既定 0.35 / 0.25）を超える。広がり・狭まりの両方を測る。 |
| 浅い岸 | 左右の水際から横断方向へ `bankProbeOffset` m（既定 2 m）外側を測る。岸が中心線の地表より `minBankRise` m 以上高いことを確認する。地表を取れない岸は別の違反にする。氾濫原・開放水域を許容するため既定 0（無効）。 |
| 埋没 | 地表が水面より `maxBuriedDepth` m（既定 0.1 m）を超えて高い。 |
| 浮いた川床 | 水面から深さを引いた高さが地表より `maxBedGap` m（既定 0.5 m）を超えて高い。 |
| 地表欠損 | 対象地点に照会可能な地表がない。 |
| 流出先 | 任意の `outlet`（水域ノード）を指定したら、下流端が湖・矩形水域・Horizon 海の基準面に入り、`maxOutletHeightDifference` m（既定 0.5 m）以内であることを確認する。省略時は開放端として扱う。 |

地形照会は `TrySampleTerrainWorld` を使い、現在有効な Terrain の最上面を採る。任意の `terrain` ノードで地形を限定できる。穴や未ロード領域に地表がないときは合格にしない。滝は上流・下流の川を分け、落下区間を既存 Waterfall の制作経路で表現できる。閉じた湖は川の検査対象から外れるが、川の流出先として指定できる。

落差・幅・水深の変化率の上限は 0 で無効。符号が混在する場合は流向に依存する逆勾配・急な落差・流出先の判定を省く。

結果は `valid`、標本数、違反の全件数、先頭最大 64 件の種類・ワールド座標と該当する差分 `differenceMeters` [m]・変化率 `rate` [m/m] を返す。地形照会は 8192 標本、最大 1048576 組までとし、岸を測る場合は標本ごとに 3 地点分を予算へ数える。制御点や形状が不正な場合、または照会予算を超える場合は操作エラーを返す。検査は通常保存と独立し、地形・水域の自動修正や実行中の強制は行わない。
