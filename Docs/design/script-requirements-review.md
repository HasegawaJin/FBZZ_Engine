# Script 必須設定の確認と修正導線

ユーザー承認: 2026-09-29「それ実装して」。不足一覧・Inspector への移動・修正後の再検証を実装する。

## 動作

- View > Panels > Script Requirements、またはコマンドパレットの必須設定チェックから開く。
- 検証時だけ Engine の必須設定検証器でアセットを解決し、対象・Script・項目・理由を一覧化する。常時ロードはしない。
- 一覧のクリックで Hierarchy 選択、Inspector のロック解除、Script と入れ子の展開、該当行の強調とスクロールを行う。
- Component / Script 自体の不足はフィールドではなく Script の警告欄へ移動する。
- 修正後の再検証で残件数を更新する。未ロードの Script がある場合は検証未完了を明記する。
- 検証と選択は共通 Operator を経由し、パレット・AI バスでも同じ処理を使う。

## 寿命と既存動作

- 結果は検証時点のスナップショット。Scene、GameObject GUID、Script 実体の InspectionId で対象を再解決する。型名や配列順のみでは選ばない。
- 再検証で世代を更新し、古い世代の行番号による選択を拒否する。破棄・Script 差し替え後は再検証を促す。
- Play 中・ホットリロード中は新しい検証や移動を止める。Inspector の強調は対象から選択が移ったら解除する。
- Awake で設定される参照を許す既存のライフサイクルを維持する。再生前検証は報告のみ、Start の可否は全 Awake 後のランタイム検証で決める。
- フィールドの照合には保存用のキーを使い、表示名の翻訳と独立させる。対象が非表示の場合は Script の先頭で理由を示す。
- アセットの自動割当やシーン保存は行わない。既存 Inspector の編集と Undo を利用する。

## 確認項目

同型 Script の識別、並べ替え、差し替え・破棄、Scene 切り替え、古い結果、参照修正後の再検証、未ロード Script、入れ子フィールドと折りたたみ、実際の Editor の起動と再生を確認する。
