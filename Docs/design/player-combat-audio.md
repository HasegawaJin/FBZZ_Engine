# Playerの戦闘SE — 両手剣

2026-09-14。金属の接触・短い抵抗・振り抜けで、攻撃が通った手応えを作る。
合成元は `GreenWare/Tools/SfxGen/gen_greatsword.py`。外部録音素材は使わない。

## 音源

`GreenWare/Assets/Sound/SE/Weapon/SE_GS_*.wav`、36本。
48kHz / 16bit PCM / mono。合成時のfloat64と、配布するWAVのビット深度は別。

| 系統 | 本数 | 役割 |
|---|---:|---|
| Swing Down / Up / Spin / Slide / Air / Finish / Charge | 各2、計14 | 切り下ろし・切り上げ・回転・滑り込み・空中・締め・溜め解放 |
| Hit / Hit Heavy | 3 / 2 | 短い接触＋摩擦＋装甲の響き。締めと溜めは重い側 |
| Guard / Parry / ParryJust | 各2、計6 | 受け止める／弾く／Justの成功を区別。切断音は重ねない |
| Execute | 2 | 切断の約95ms後に構造の破断が続く |
| Dash / Ready | 2 / 1 | 踏み込みと入力直後の小さい構え |
| Charge Loop / Charge Full / Flux | 各1、計3 | 持続、満溜め、Just回避の報酬を区別 |
| Cadence / Core | 1 / 2 | 拍が合った通知とコア命中の追加層 |

拍は専用の短い音を既存の五音音階で変調する。ボス側の衝撃音・部位落下音は本変更の対象外。

## 再生契約

- 振り素材の包絡の主峰は開始60ms。`se::SWORD_SWING_PEAK_SECONDS` と対。
- `BladeComponent` は入力直後にReadyを小さく返し、Startup残り60msで振りを一度再生する。
- 物理接触で判定が前倒しされた場合も、そのフレームで未再生の振りを出す。接触音を待たせない。
- 再生する振りは現在のクリップの用途から選ぶ。左右の刀や固定の3段分類では選ばない。
- キャンセルで未再生予約を捨てる。新しい攻撃は予約を張り直す。
- とどめも判定60ms前に振り、成功したときだけExecuteを鳴らす。
- 溜め解放素材に命中を焼き込まない。空振りは振り音のみ。
- Charge Loopは整数Hzの部分音と24Hz AMによる1秒周期。フェードは既存LoopVoiceが担当する。
- シーンのAudioSourceとバス音量は変更しない。

## 命中の種類（2026-09-15追記）

- 通常部位は既存の刃色と斬撃音。装甲への命中は青白い小さな火花・軽い金属音・短い止め。
- 弱点（コアまたはダウン中）は金色の火花とコア音、部位耐久を削り切った瞬間は大きい火花と破片音・強い止め。
- 同時に複数へ当たった場合は破壊、弱点、通常、装甲の順に一つを選び、その接触面に演出を置く。
- 追加ヒットでは弱点音を重ねず、部位を削り切った場合のみ破片音を鳴らす。締めは振り始めに確定した段を参照する。

## 再生成

NumPyが必要。リポジトリルートで以下を実行する。

```text
python GreenWare/Tools/SfxGen/gen_greatsword.py --output GreenWare/Assets/Sound/SE/Weapon --preview <preview.wav>
```

同じseedから同じPCMを生成する。既存metaは保存し、新規WAVにのみGUIDを発行する。
プレビューは6連撃→ガード→パリィ→Just→溜め→とどめ→Flux。比較用の合成シーケンスで、実機録音ではない。

## 検証

WAV形式、振幅、DC、ループ境界、参照の実在、GUID重複、再生成の一致を確認する。
ピークやクレストは故障検出・比較に使い、音の気持ちよさの合否には使わない。
C++のビルドとゲーム内の音量・同期・連続攻撃の聴感はVS Code / Visual Studioで確認する。

## 旧素材

Weapon内の旧双剣SE、旧銃バッテリーSE、旧版退避の計56本と付随metaは、パス・ファイル名・GUIDの参照を監査して削除した。
旧生成器 `gen_blade.py` は本生成器へ交代。既存シーンのGUIDを新しい音へ勝手に置換しない。
