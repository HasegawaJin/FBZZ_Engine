# パリィ連撃チャンス

成功後は世界を 0.25 倍、プレイヤーは等速、斬撃は 1.65 倍で 2 秒進める。Just は 2.6 秒。
再成功は残り時間を更新する。SlowMotion PostEffect は世界の遅さに追従する。
攻撃押下を一撃ずつ受け付け、一撃まで先行入力する。この間は溜め・自動とどめへの分岐を避ける。
パリィボタンによるとどめと回避は優先する。HUD は攻撃の割り当て・連打指示・残り時間を表示する。

TimeManager に従来の演出スローと独立した連撃層を置く。ポーズ・ヒットストップ中は残り時間も止める。
死亡・入力拘束・とどめ・破棄時は解除する。
プレイヤーの補正倍率は同フレームの scaled/unscaled dt 比で求め、移動・剛体・Animator に適用する。
Animator は speed と別のランタイム倍率を持ち、FreezeAnimation の復帰値を汚さない。
剛体は既存の Volume と局所時間倍率を合成する。斬撃は専用時計で発生・硬直・拍を揃える。

検証：通常/Just、連打/長押し、再成功、回避、とどめ、死亡、ポーズ、シーン移動。
3 ステージの HUD と割り当て、低 FPS の移動と判定を全体ビルド後に実機確認する。

## GreenWare へ反映する手順

GreenWare はエンジンのソースヘッダーではなく `SDK/0.1.0/include` と同 SDK のライブラリを参照する。
全体ビルドだけでは SDK は更新されない。今回追加した `SetLocalTimeScale` とランタイムの構造変更を
揃えて反映するため、VS Code で `CMake: Build SDK (Debug)` を実行し、GreenWare を再 Configure・ビルドする。
Development / Release で遊ぶ場合は、対応する `CMake: Build SDK (...)` も実行する。
ヘッダーだけをコピーすると古い DLL と ABI が食い違うため、SDK ターゲットで一式更新する。

## カメラの追従（2026-09-15）

成功時の相手をCameraFollowManagerへ渡し、TPSがプレイヤーと相手の間へ注視点を最大2m寄せる。
距離は最大1m追加、0.22秒の補間で出入りする。旋回は最大45度/秒、ピッチは10〜28度へ緩やかに補正する。
手動視点入力中と入力後0.8秒は自動構図を外す。ポーズでは補間を止める。
ラッシュ中のFOVパンチは35%へ抑え、連打で画角が跳ね続けることを防ぐ。カットインで操作を奪わない。
