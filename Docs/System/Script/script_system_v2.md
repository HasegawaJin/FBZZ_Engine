# FBZZ Script System v2 — 設計書

作成日: 2026-06-10

---

## 設計思想

FBZZ Script の問題の本質は「ボイラープレートが多い」ではなく、  
**「宣言とメタデータが 2 箇所に分離している」** こと。

| 現状 | v2 |
|------|-----|
| フィールド宣言 + Reflect() を手で同期 | `FBZZ_FIELD` 1 行に集約 |
| TYPE_NAME + GetTypeName + 登録を手書き | `FBZZ_SCRIPT` が全部担う |
| EntityID は IsValid + GetGameObject の 2 ステップ | `EntityRef` が 1 ステップに |
| int でキーコードを保持しキャスト | `KeyCode` をそのまま扱う |
| `transform->position` で `->` が必要 | `transform.position` で直接アクセス |
| `m_deltaTime` など内部命名が API に漏れる | `deltaTime` / `time` に統一 |
| `Transform::worldScale` 命名の不統一 | `scale` に統一 |
| Script 基底に全 Proxy が詰まっている | グラフィックス用途に絞る |

**外部ツール・新言語は導入しない。**  
既存の `ScriptCodeGen` をヘッダツール (FHT) として拡張し、  
C++ マクロと軽量コード生成の組み合わせで解決する。

## ユーザーが書くスクリプト（完成形）

```cpp
#pragma once
#include <Engine/Scene/Script.hpp>
#include "BulletShooterComponent.generated.hpp"  // FHT が生成

using namespace fbzz::scene;
using namespace fbzz::math;

namespace sandbox {

class BulletShooterComponent : public Script {
    FBZZ_SCRIPT(BulletShooterComponent)

public:
    FBZZ_GROUP("Prefab")
    FBZZ_FIELD(PrefabRef, bulletPrefab, {},             "Bullet Prefab")
    FBZZ_FIELD(EntityRef, muzzle,       {},             "Muzzle")

    FBZZ_GROUP("Firing")
    FBZZ_FIELD(KeyCode,   fireKey,  KeyCode::MouseLeft, "Fire Key")
    FBZZ_FIELD_RANGE(float, fireRate, 5.0f,             "Fire Rate", 0.1f, 30.0f)

    void OnUpdate(float dt) override;

private:
    float m_cooldown = 0.f;
    void Fire();
};

} // namespace sandbox
```

現行と比べて **消えるもの**:
- `static constexpr const char* TYPE_NAME`
- `const char* GetTypeName() const override`
- `void Reflect(IReflector& r) override { ... }`
- `(int)KeyCode::MouseLeft` キャスト
- `SandboxScripts.cpp` の `#include` と `FBZZ_REGISTER_SCRIPT` (FHT が自動挿入)

## マクロ定義

### Script.hpp に追加するマクロ

コード生成が走っていない場合は `FBZZ_GENERATED_BODY()` は空展開となり、  
スクリプトはコンパイルが通るが Inspector に何も表示されない（フォールバック）。

```cpp
// FBZZ_SCRIPT — TYPE_NAME + GetTypeName + Reflect の宣言をまとめる。
// .generated.hpp が存在すれば FBZZ_GENERATED_BODY() がそれを実装する。
#define FBZZ_SCRIPT(T)                                            \
    static constexpr const char* TYPE_NAME = #T;                 \
    const char* GetTypeName() const override { return TYPE_NAME; }\
    FBZZ_GENERATED_BODY()

// .generated.hpp がインクルードされるまでの空フォールバック
#ifndef FBZZ_GENERATED_BODY
#define FBZZ_GENERATED_BODY() void Reflect(IReflector&) override {}
#endif

// ── フィールド宣言マクロ ──────────────────────────────────────────
// コンパイル時はメンバ宣言にのみ展開する。
// FHT はこれらの行をパースして .generated.hpp 内の Reflect() を生成する。

// 標準フィールド
#define FBZZ_FIELD(Type, Name, Default, DisplayName)              \
    Type Name = Default

// スライダー付き float / int
#define FBZZ_FIELD_RANGE(Type, Name, Default, DisplayName, Min, Max) \
    Type Name = Default

// enum ドロップダウン
// Labels は文字列リテラルの可変引数: "Off", "Low", "High"
#define FBZZ_FIELD_ENUM(Type, Name, Default, DisplayName, ...)    \
    Type Name = Default

// 読み取り専用ラベル (シリアライズ対象外、計算値の表示用)
#define FBZZ_FIELD_READONLY(Type, Name, DisplayName)              \
    Type Name = {}

// Inspector のグループ見出し (値なし)
#define FBZZ_GROUP(Label)
```

### .generated.hpp の形式

FHT が `BulletShooterComponent.hpp` をパースして生成する。

```cpp
// AUTO-GENERATED by FBZZ Header Tool — do not edit manually
// Source: BulletShooterComponent.hpp

#pragma once

#undef  FBZZ_GENERATED_BODY
#define FBZZ_GENERATED_BODY()                                        \
    void Reflect(IReflector& r_) override {                          \
        r_.Group("Prefab");                                          \
        r_.Field     ("Bullet Prefab",  bulletPrefab);               \
        r_.Field     ("Muzzle",         muzzle);                     \
        r_.Group("Firing");                                          \
        r_.Field     ("Fire Key",       fireKey);                    \
        r_.FloatRange("Fire Rate",      fireRate, 0.1f, 30.0f);     \
    }
```

`#undef / #define` で再定義することで、インクルード順に関わらず有効になる。  
.generated.hpp が存在しない場合は `FBZZ_SCRIPT` のフォールバックが使われる。

## FBZZ Header Tool (FHT) — ScriptCodeGen の拡張

### 追加する処理

既存の `ScriptCodeGen::CreateScript()` が生成する雛形を v2 形式に更新し、  
加えて `GenerateReflect()` を新設する。

```
FHT のパース対象:
  FBZZ_FIELD      (Type, Name, Default, DisplayName)
  FBZZ_FIELD_RANGE(Type, Name, Default, DisplayName, Min, Max)
  FBZZ_FIELD_ENUM (Type, Name, Default, DisplayName, Labels...)
  FBZZ_FIELD_READONLY(Type, Name, DisplayName)
  FBZZ_GROUP      (Label)
  class XxxComponent : public Script  — クラス名検出用
```

パーサーは行単位のテキストスキャンでよい。C++ の完全パースは不要。  
(UHT が専用パーサーを持つのはテンプレート・継承・属性を深く解析するため。FHT はそこまで必要ない。)

### 呼び出しタイミング

| タイミング | 呼び出し元 |
|-----------|-----------|
| スクリプト新規作成 | `CreateScript()` 内で自動実行、空の .generated.hpp を配置 |
| .hpp 保存時 | `ScriptDllLoader` のファイル監視が変更を検出して実行 |
| エディタ起動時 | `EditorApp::OnInit()` で全スクリプトを一括再生成 |

### 新しいスクリプトテンプレート

`CreateScript()` が出力する雛形を以下に変更する。

```cpp

public:
    // ── Inspector フィールド ─────────────────
    // FBZZ_FIELD(float, speed, 5.0f, "Speed")

    void OnUpdate(float dt) override { (void)dt; }
};

} // namespace sandbox
```

## transform アクセスの改善

### 問題

`ScriptTransformProxy` は `operator->()` で `Transform*` を返すため、  
フィールド読み書きに `->` が必要になる。

```cpp
// Before — -> が混在して読みにくい
transform->localPosition += direction * speed * dt;
transform->localRotation = transform->rotation = rot;
auto fwd = transform->Forward();   // メソッドは大文字始まり
```

### 解決: `position` = ローカル、`worldPosition` = ワールドに逆転する

現状は「書く方がローカル名、読む方がワールド名」で混乱する。  
Godot と同じく **`position` をデフォルト（ローカル）にして世界座標に `world` プレフィックス** を付ける。

```cpp
struct Transform {
    // ── 書く側 (ユーザーが操作する) ─────────────────────
    Vector3    position;    // ローカル座標  (旧 localPosition)
    Quaternion rotation;    // ローカル回転  (旧 localRotation)
    Vector3    scale;       // ローカルスケール (旧 localScale)

    // ── 読む側 (TransformSystem が毎フレーム更新) ─────────
    Vector3    worldPosition;   // ワールド座標  (旧 position)
    Quaternion worldRotation;   // ワールド回転  (旧 rotation)
    Vector3    worldScale;      // ワールドスケール (変更なし)

    Vector3 Forward() const;   // worldRotation から算出
    Vector3 Up()      const;
    Vector3 Right()   const;
};
```

`ScriptTransformProxy` は MSVC `__declspec(property)` でフィールドを `.` アクセスに公開する。

```cpp
struct ScriptTransformProxy {
    __declspec(property(get=_Pos,       put=_SetPos))       Vector3    position;
    __declspec(property(get=_Rot,       put=_SetRot))       Quaternion rotation;
    __declspec(property(get=_Scl,       put=_SetScl))       Vector3    scale;
    __declspec(property(get=_WPos,      put=_SetWPos))      Vector3    worldPosition;
    __declspec(property(get=_WRot))                         Quaternion worldRotation;  // 読み取り専用
    __declspec(property(get=_Fwd))                          Vector3    forward;        // 読み取り専用
    __declspec(property(get=_Up))                           Vector3    up;
    __declspec(property(get=_Right))                        Vector3    right;

    void    Translate   (const Vector3& v) const;
    void    Rotate      (const Vector3& axis, float deg) const;
    void    LookAt      (const Vector3& target) const;
    float   DistanceTo  (const GameObject& other) const;
    Vector3 DirectionTo (const GameObject& other) const;

    [[deprecated("Use transform.position / transform.worldPosition directly")]]
    Transform* operator->() const;
};
```

```cpp
// Before
transform->localPosition += direction * speed * dt;
transform->position       = transform->localPosition;  // ワープ時に両方書く必要があった
auto fwd = transform->Forward();

// After
transform.position += direction * speed * dt;  // ローカルに加算
auto worldPos = transform.worldPosition;        // ワールド読み取りは明示的
auto fwd      = transform.forward;              // 小文字プロパティ
```

**ワープ（localPosition と position の二重更新）が不要になる理由:**  
TransformSystem が `position` (ローカル) からワールド値を毎フレーム計算するため、  
スクリプトからは `transform.position` だけ書けばよい。
`worldPosition` への直接書き込みはエディタ・物理システム専用にする。

## タイミング情報の命名改善

`m_` プレフィックスはエンジン内部の命名規則。ユーザー向け公開 API では外す。

```cpp
// Before
float    m_deltaTime
float    m_time
float    m_unscaledDeltaTime
uint64_t m_frameCount

// After
float    deltaTime
float    time
float    unscaledDeltaTime
uint64_t frameCount
```

既存コードとの互換は `[[deprecated]]` alias で対応する。

```cpp
[[deprecated("Use deltaTime")]]
float& m_deltaTime = deltaTime;
```

## 新型: EntityRef

`EntityID` の代替として `EntityRef` を追加する。  
`IsValid()` + `GetGameObject()` の 2 ステップを 1 つに集約する。

```cpp
// EntityRef — EntityID を内包し、ScriptSceneProxy 経由で安全に解決する。
// IReflector は EntityID と同じ Inspector UI・シリアライズフローを使う。
struct EntityRef {
    EntityID id;

    bool IsValid() const { return id.IsValid(); }

    // scene プロキシを渡して GameObject* を解決する。見つからなければ nullptr。
    GameObject* Resolve(const ScriptSceneProxy& scene) const {
        return id.IsValid() ? scene.GetGameObject(id) : nullptr;
    }
};
```

`IReflector` に `Field(const char*, EntityRef&)` オーバーロードを追加し、  
Inspector の D&D アサインとシリアライズを `EntityID` と同じフローで処理する。

```cpp
// Before
if (muzzleEntityId.IsValid()) {
    auto* go = scene.GetGameObject(muzzleEntityId);
    if (go) spawnPos = go->transform.position;
}

// After
if (auto* go = muzzle.Resolve(scene))
    spawnPos = go->transform.position;
```

## KeyCode をフィールドとして直接扱う

`IReflector` に `KeyCode` オーバーロードを追加し、`int` キャストを不要にする。

```cpp
// IReflector 追加分
virtual void Field(const char* name, input::KeyCode& v) {}
// Inspector: キー名ドロップダウン

// Before

// After
KeyCode fireKey = KeyCode::MouseLeft;
input.GetKeyDown(fireKey);
```

## Invoke ハンドル化

`Invoke` / `InvokeRepeating` がハンドルを返し、個別キャンセルを可能にする。  
既存の一括 `CancelInvoke()` は維持する。

```cpp
// InvokeHandle — ID のみを持つ軽量値型
struct InvokeHandle {
    uint32_t id = 0;
    bool IsValid() const { return id != 0; }
};

// Before — 全キャンセルしかできない
InvokeRepeating([this]{ SpawnEnemy(); }, 2.f, 3.f);
CancelInvoke();

// After — 個別キャンセルが可能
auto h = InvokeRepeating([this]{ SpawnEnemy(); }, 2.f, 3.f);
CancelInvoke(h);
```

## Script 基底クラスの改訂

### 削除するもの

| 削除対象 | 理由 |
|---------|------|
| `ScriptMemoryProxy memory` | ゲームロジック用アロケータ。グラフィックス特化の Script には不要 |
| `ScriptUIProxy ui` | UI 専用の `UIScript` 基底クラスに分離する |
| `On<T>()` / `Emit<T>()` | 静的グローバル購読リストは設計の負債。`Scene::EventBus` として Script 外に切り出す |
| `OnFixedUpdate(float)` | 物理固定ステップフック。未使用のまま残り続けていた |
| `OnPreRender()` / `OnPostRender()` | `OnSetupRenderPasses` と役割が重複する予約フック |
| Script 基底の `Find` / `FindWithTag` 等委譲メソッド | `scene.*` に一本化するため `[[deprecated]]` を経て削除 |

### 削除後の Script（概形）


## IReflector の整理

`Reflect()` からUI情報 (`Header` / `Separator` / `Label`) を排除する。  
グループ情報は `FBZZ_GROUP` メタデータとして FHT が .generated.hpp に書き出し、  
Inspector が静的に読む。

```cpp
struct IReflector {
    virtual ~IReflector() = default;

    // ── プリミティブ (pure virtual) ─────────────────
    virtual void Field(const char* name, float& v)            = 0;
    virtual void Field(const char* name, int& v)              = 0;
    virtual void Field(const char* name, bool& v)             = 0;
    virtual void Field(const char* name, math::Vector2& v)    = 0;
    virtual void Field(const char* name, math::Vector3& v)    = 0;
    virtual void Field(const char* name, math::Vector4& v)    = 0;
    virtual void Field(const char* name, std::string& v)      = 0;
    virtual void Field(const char* name, math::Quaternion& v) = 0;

    // ── 参照型 (デフォルト実装あり) ────────────────
    virtual void Field(const char* name, EntityID& v)         {}
    virtual void Field(const char* name, EntityRef& v)        { Field(name, v.id); }
    virtual void Field(const char* name, PrefabRef& v)        { Field(name, v.path); }
    virtual void Field(const char* name, input::KeyCode& v)   {}  // 追加

    // ── 付加情報付き (デフォルトは Field へフォールバック) ─
    virtual void FloatRange(const char* name, float& v, float min, float max) { Field(name, v); }
    virtual void Enum(const char* name, int& v, std::span<const char* const> labels) { Field(name, v); }

    // ── グループ (Serializer では無視) ─────────────
    virtual void Group(const char* label) {}

    // ── 読み取り専用 (Serializer では無視) ─────────
    virtual void Readonly(const char* name, const std::string& v) {}
    virtual void Readonly(const char* name, float v)              {}
    virtual void Readonly(const char* name, int v)                {}
};
// 削除: Header / Separator / Label / KeyCodeField / FieldWithTooltip
```

## 移行計画

### フェーズ 1 — 基盤（既存コードを壊さない）

1. `FBZZ_FIELD` / `FBZZ_GROUP` / `FBZZ_SCRIPT` マクロを `Script.hpp` に追加  
2. `FBZZ_GENERATED_BODY()` の空フォールバックを `Script.hpp` に追加  
3. `FHT::GenerateReflect()` を `ScriptCodeGen.cpp` に実装  
4. `CreateScript()` のテンプレートを v2 形式に変更  
5. エディタ起動時 / ファイル保存時に `GenerateReflect()` を呼び出す  

→ **この時点で新規スクリプトは v2 形式で書ける。既存スクリプトは無変更で動く。**

### フェーズ 2 — 型追加

6. `EntityRef` を追加し `IReflector::Field(EntityRef&)` を実装  
7. `IReflector::Field(KeyCode&)` を実装 (Inspector + Serializer)  
8. `InvokeHandle` と `CancelInvoke(handle)` を追加  

### フェーズ 3 — スリム化

9. `ScriptMemoryProxy` / `On<T>` / `Emit<T>` を削除  
10. `OnFixedUpdate` / `OnPreRender` / `OnPostRender` を削除  
11. `IReflector` から `Header` / `Separator` / `Label` 系 API を削除  
12. Script 基底の委譲メソッドに `[[deprecated]]` を付与  

### フェーズ 4 — 既存スクリプト移行

13. `Assets/Scripts/*.hpp` を v2 形式に書き直す  
    - `EntityID` → `EntityRef`  
    - `int fireKey = (int)KeyCode::X` → `KeyCode fireKey = KeyCode::X`  
    - `Reflect()` 手書き → `FBZZ_FIELD` + FHT 生成に置き換え
