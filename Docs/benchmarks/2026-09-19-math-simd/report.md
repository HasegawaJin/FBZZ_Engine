## 判定の基準

- 変化 = (候補 − 基準) / 基準。値は各実行の中央値の中央値で、基準と候補を交互に実行して測った
- 改善: −3% 以下 / 変化なし: ±3% 未満 / 注意: +3〜5% / 悪化: +5% 以上
- ばらつき = 各実行の中央値の (最大 − 最小) / 代表値。変化がこれより小さいものは «ノイズ内»
- 方法の詳細: [Docs/design/benchmark-report.md](../../design/benchmark-report.md)
