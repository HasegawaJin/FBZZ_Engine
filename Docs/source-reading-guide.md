# FBZZEngine ソースコードの読み順

- 状態: 2026-11-24 の作業ツリーで参照先を確認。

**最初のゴールは、ゲームを起動してから、シーンの物体が画面に出るまでを自分の言葉で説明できること。** 起動の入口は、GameHub の標準テンプレートから作ったゲームを単体実行する場合にそろえた。最初の6項目で1フレームを一周する。その後は同じフレームに戻り、物理・描画・編集を一つずつ掘る。後半の矢印はファイルを開くおすすめの順番を表す。
