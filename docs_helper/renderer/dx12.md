# Renderer / DX12 Implementation

DX12 具体実装。`engine/src/Renderer/Platform/DX12/` に配置し、上位レイヤーからは隠蔽する。
**Step 6 (DX12 移行時) に実装する。現時点では設計参照のみ。**

---

## クラス一覧

| クラス | 基底 | 役割 |
|--------|------|------|
| `DX12Renderer` | `IRenderer` | デバイス・コマンドキュー・スワップチェーン管理、描画実行 |
| `DX12Buffer` | `IBuffer` | 頂点・インデックスバッファ (デフォルトヒープ) |
| `DX12ConstantBuffer` | `IConstantBuffer` | 定数バッファ (アップロードヒープ + CBV デスクリプタ) |
| `DX12Shader` | `IShader` | DXIL バイトコード保持のみ (PSO に渡す) |
| `DX12Texture` | `ITexture` | テクスチャ + SRV デスクリプタ |
| `DX12PipelineState` | `IPipelineState` | `ID3D12PipelineState` (RS/BS/DS + シェーダーを事前ベイク) |
| `DX12RenderTarget` | `IRenderTarget` | オフスクリーン RT + RTV/SRV デスクリプタ |

## DX12Renderer

```cpp
namespace fbzz::renderer {

class DX12Renderer : public IRenderer {
public:
    bool Init(HWND hwnd, uint32_t width, uint32_t height);
    void Shutdown();

    void BeginFrame() override;
    void EndFrame()   override;
    void Clear(const math::Vector4& color) override;

    std::shared_ptr<IBuffer>         CreateVertexBuffer(const void* data, size_t sizeBytes, uint32_t stride) override;
    std::shared_ptr<IBuffer>         CreateIndexBuffer(const void* data, uint32_t count) override;
    std::shared_ptr<IConstantBuffer> CreateConstantBuffer(size_t sizeBytes) override;
    std::shared_ptr<IShader>         CreateShader(const std::string& path) override;
    std::shared_ptr<ITexture>        CreateTexture(const std::string& path) override;
    std::shared_ptr<IPipelineState>  CreatePipelineState(const PipelineStateDesc& desc) override;

    void Submit(const DrawCall& call) override;
    void Resize(uint32_t width, uint32_t height) override;

    std::shared_ptr<IRenderTarget> CreateRenderTarget(uint32_t width, uint32_t height) override;
    void SetRenderTarget(std::shared_ptr<IRenderTarget> rt) override;
    void SetSampler(uint32_t slot, SamplerMode mode) override;

    // 内部アクセス (DX12Buffer 等が使う)
    ID3D12Device*              GetDevice()       const { return m_device.Get(); }
    ID3D12GraphicsCommandList* GetCommandList()  const { return m_commandList.Get(); }

private:
    static constexpr uint32_t FRAME_COUNT = 2;  // ダブルバッファリング

    Microsoft::WRL::ComPtr<ID3D12Device>              m_device;
    Microsoft::WRL::ComPtr<ID3D12CommandQueue>        m_commandQueue;
    Microsoft::WRL::ComPtr<IDXGISwapChain3>           m_swapChain;
    Microsoft::WRL::ComPtr<ID3D12CommandAllocator>    m_commandAllocators[FRAME_COUNT];
    Microsoft::WRL::ComPtr<ID3D12GraphicsCommandList> m_commandList;

    // デスクリプタヒープ
    Microsoft::WRL::ComPtr<ID3D12DescriptorHeap> m_rtvHeap;    // RTV (非シェーダー可視)
    Microsoft::WRL::ComPtr<ID3D12DescriptorHeap> m_dsvHeap;    // DSV (非シェーダー可視)
    Microsoft::WRL::ComPtr<ID3D12DescriptorHeap> m_cbvSrvHeap; // CBV/SRV (シェーダー可視)
    Microsoft::WRL::ComPtr<ID3D12DescriptorHeap> m_samplerHeap;// Sampler (シェーダー可視)

    // バックバッファ
    Microsoft::WRL::ComPtr<ID3D12Resource> m_renderTargets[FRAME_COUNT];
    Microsoft::WRL::ComPtr<ID3D12Resource> m_depthStencilBuffer;

    // ルートシグネチャ (全シェーダー共通)
    Microsoft::WRL::ComPtr<ID3D12RootSignature> m_rootSignature;

    // CPU-GPU 同期
    Microsoft::WRL::ComPtr<ID3D12Fence> m_fence;
    uint64_t m_fenceValues[FRAME_COUNT] = {};
    HANDLE   m_fenceEvent = nullptr;

    uint32_t m_frameIndex = 0;
    uint32_t m_width  = 0;
    uint32_t m_height = 0;

    // Submit() で蓄積した DrawCall キュー (layer ごとに分類)
    std::array<std::vector<DrawCall>, 3> m_queues;  // OPAQUE / TRANSPARENT / OVERLAY
};

} // namespace fbzz::renderer
```

## Root Signature

全シェーダー共通の Root Signature を `Init()` 時に 1 つ生成する。

| Root Parameter | 種別 | 内容 |
|---------------|------|------|
| 0 | Root CBV | b0: CameraConstants |
| 1 | Root CBV | b1: ObjectConstants |
| 2 | Root CBV | b2: MaterialConstants |
| 3 | Root CBV | b3: LightConstants |
| 4 | Descriptor Table | t0〜t7: テクスチャ SRV |
| 5 | Descriptor Table | s0〜s1: サンプラー |

Root CBV は 1 DrawCall あたり書き換え頻度が高い b0〜b3 に最適。
テクスチャはデスクリプタテーブル経由で最大 8 スロット同時バインド。

## BeginFrame / EndFrame の処理フロー

```
BeginFrame()
│
├─ フェンス待機 (前フレームの GPU 完了を確認)
├─ m_commandAllocators[frameIndex]->Reset()
├─ m_commandList->Reset(allocator, nullptr)
├─ リソースバリア: PRESENT → RENDER_TARGET (バックバッファ)
└─ OMSetRenderTargets / RSSetViewports / RSSetScissorRects

EndFrame()
│
├─ [OPAQUE キュー] をソートなしで発行
├─ [TRANSPARENT キュー] を奥から手前にソートして発行
├─ [OVERLAY キュー] をソートなしで発行
├─ リソースバリア: RENDER_TARGET → PRESENT
├─ m_commandList->Close()
├─ m_commandQueue->ExecuteCommandLists(...)
├─ m_swapChain->Present(1, 0)
└─ フェンスをシグナル / frameIndex を更新
```

## Submit の処理フロー

`Submit()` は DrawCall をキューに追加するだけ。実際の GPU コマンドは `EndFrame()` 内で発行する。

```
DX12Renderer::FlushQueue(queue)  ← EndFrame() 内から呼ぶ
│
├─ SetPipelineState(DX12PipelineState::GetPSO())
├─ SetGraphicsRootSignature(m_rootSignature)
├─ SetDescriptorHeaps([cbvSrvHeap, samplerHeap])
├─ SetGraphicsRootConstantBufferView(0, constantBuffers[0]->GetGPUVirtualAddress())  // b0
├─ SetGraphicsRootConstantBufferView(1, constantBuffers[1]->GetGPUVirtualAddress())  // b1
├─ SetGraphicsRootConstantBufferView(2, constantBuffers[2]->GetGPUVirtualAddress())  // b2
├─ SetGraphicsRootConstantBufferView(3, constantBuffers[3]->GetGPUVirtualAddress())  // b3
├─ SetGraphicsRootDescriptorTable(4, textures の SRV デスクリプタテーブル)
├─ IASetVertexBuffers / IASetIndexBuffer
└─ DrawIndexedInstanced / DrawInstanced
```

DX11 の `Submit()` は即時発行だが、DX12 は `EndFrame()` までキューに蓄積する点が異なる。

## DX12ConstantBuffer

```cpp
namespace fbzz::renderer {

class DX12ConstantBuffer : public IConstantBuffer {
public:
    bool Init(ID3D12Device* device, size_t sizeBytes);

    void   Update(const void* data, size_t sizeBytes) override;
    size_t GetSize() const override { return m_size; }

    D3D12_GPU_VIRTUAL_ADDRESS GetGPUVirtualAddress() const { return m_resource->GetGPUVirtualAddress(); }

private:
    Microsoft::WRL::ComPtr<ID3D12Resource> m_resource;  // D3D12_HEAP_TYPE_UPLOAD
    void*  m_mappedPtr = nullptr;  // Map() で取得した CPU 側ポインタ (永続 Map)
    size_t m_size      = 0;
};

} // namespace fbzz::renderer
```

アップロードヒープに生成し、`Init()` 時に `Map()` して `m_mappedPtr` を保持したままにする (永続 Map)。
`Update()` は `memcpy` のみ。`Unmap()` は `Shutdown()` まで呼ばない。

256 byte アライメントが必要なため、`sizeBytes` は `(sizeBytes + 255) & ~255` に切り上げる。

## DX12PipelineState

```cpp
namespace fbzz::renderer {

class DX12PipelineState : public IPipelineState {
public:
    bool Init(ID3D12Device* device, ID3D12RootSignature* rootSig,
              const PipelineStateDesc& desc, const DX12Shader& shader);

    const PipelineStateDesc& GetDesc() const override { return m_desc; }

    ID3D12PipelineState* GetPSO() const { return m_pso.Get(); }

private:
    Microsoft::WRL::ComPtr<ID3D12PipelineState> m_pso;
    PipelineStateDesc m_desc;
};

} // namespace fbzz::renderer
```

`Init()` 内で `D3D12_GRAPHICS_PIPELINE_STATE_DESC` を組み立て `CreateGraphicsPipelineState()` を呼ぶ。
`PipelineStateDesc` の各フィールドを DX12 の構造体フィールドに変換する。

| `PipelineStateDesc` | `D3D12_GRAPHICS_PIPELINE_STATE_DESC` |
|---------------------|--------------------------------------|
| `RasterizerMode::SOLID` | `FillMode = D3D12_FILL_MODE_SOLID` |
| `RasterizerMode::WIREFRAME` | `FillMode = D3D12_FILL_MODE_WIREFRAME` |
| `BlendMode::OPAQUE` | `BlendEnable = FALSE` |
| `BlendMode::ALPHA_BLEND` | `BlendEnable = TRUE`, `SrcBlend = SRC_ALPHA`, `DestBlend = INV_SRC_ALPHA` |
| `BlendMode::ADDITIVE` | `BlendEnable = TRUE`, `SrcBlend = ONE`, `DestBlend = ONE` |
| `DepthMode::DEPTH_ON` | `DepthEnable = TRUE`, `DepthWriteMask = ALL` |
| `DepthMode::DEPTH_READ` | `DepthEnable = TRUE`, `DepthWriteMask = ZERO` |
| `DepthMode::DEPTH_OFF` | `DepthEnable = FALSE` |

## DX12Shader

```cpp
namespace fbzz::renderer {

class DX12Shader : public IShader {
public:
    bool Init(const std::string& path);

    const std::string& GetPath() const override { return m_path; }

    D3D12_SHADER_BYTECODE GetVS() const { return { m_vsBlob.data(), m_vsBlob.size() }; }
    D3D12_SHADER_BYTECODE GetPS() const { return { m_psBlob.data(), m_psBlob.size() }; }

private:
    std::vector<char> m_vsBlob;
    std::vector<char> m_psBlob;
    std::string       m_path;
};

} // namespace fbzz::renderer
```

`dxc.exe` で事前コンパイルした `.cso` (DXIL) をバイナリ読み込みするだけ。
バイトコードは `DX12PipelineState::Init()` に渡す。シェーダー自体はバインドしない。

## DX11 との主な差異まとめ

| 項目 | DX11 | DX12 |
|------|------|------|
| コマンド発行タイミング | `Submit()` で即時 | `EndFrame()` でまとめて発行 |
| 定数バッファ転送 | `Map(WRITE_DISCARD)` | アップロードヒープへの `memcpy` (永続 Map) |
| パイプラインステート | RS/BS/DS を個別 Set | `ID3D12PipelineState` として事前ベイク |
| テクスチャバインド | `PSSetShaderResources` | デスクリプタテーブル経由 |
| CPU-GPU 同期 | ドライバが管理 | フェンスで明示的に管理 |
| ルートシグネチャ | なし | 全シェーダー共通で 1 つ定義 |
| バリア管理 | 不要 | PRESENT ↔ RENDER_TARGET を明示的に切り替え |
