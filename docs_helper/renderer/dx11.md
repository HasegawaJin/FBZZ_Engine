# Renderer / DX11 Implementation

DX11 具体実装。`engine/src/Renderer/Platform/DX11/` に配置し、上位レイヤーからは隠蔽する。

---

## クラス一覧

| クラス | 基底 | 役割 |
|--------|------|------|
| `DX11Renderer` | `IRenderer` | デバイス・スワップチェーン管理、描画実行 |
| `DX11Buffer` | `IBuffer` | 頂点・インデックスバッファ |
| `DX11ConstantBuffer` | `IConstantBuffer` | 定数バッファ (UpdateSubresource) |
| `DX11Shader` | `IShader` | VS/PS コンパイル・入力レイアウト |
| `DX11Texture` | `ITexture` | テクスチャ読み込み・SRV 管理 |
| `DX11PipelineState` | `IPipelineState` | RS/BS/DS ステートオブジェクト保持 |

## DX11Renderer

```cpp
namespace fbzz::renderer {

class DX11Renderer : public IRenderer {
public:
    bool Init(HWND hwnd, uint32_t width, uint32_t height);
    void Shutdown();

    void BeginFrame() override;
    void EndFrame()   override;
    void Clear(const math::Vector4& color) override;

    std::shared_ptr<IBuffer>         CreateVertexBuffer(const void* data, size_t sizeBytes, uint32_t stride) override;
    std::shared_ptr<IBuffer>         CreateIndexBuffer(const void* data, uint32_t count) override;
    std::shared_ptr<IConstantBuffer> CreateConstantBuffer(size_t sizeBytes) override;
    std::shared_ptr<IShader>         CreateShader(const std::string& path) override;
    std::shared_ptr<ITexture>        CreateTexture(const std::string& path) override;
    std::shared_ptr<IPipelineState>  CreatePipelineState(const PipelineStateDesc& desc) override;

    void Submit(const DrawCall& call) override;
    void Resize(uint32_t width, uint32_t height) override;

    std::shared_ptr<IRenderTarget> CreateRenderTarget(uint32_t width, uint32_t height) override;
    void SetRenderTarget(std::shared_ptr<IRenderTarget> rt) override;
    void SetSampler(uint32_t slot, SamplerMode mode) override;

    // 内部アクセス (DX11Buffer 等が使う)
    ID3D11Device*        GetDevice()        const { return m_device.Get(); }
    ID3D11DeviceContext* GetDeviceContext()  const { return m_context.Get(); }

private:
    Microsoft::WRL::ComPtr<ID3D11Device>           m_device;
    Microsoft::WRL::ComPtr<ID3D11DeviceContext>    m_context;
    Microsoft::WRL::ComPtr<IDXGISwapChain>         m_swapChain;
    Microsoft::WRL::ComPtr<ID3D11RenderTargetView> m_renderTargetView;
    Microsoft::WRL::ComPtr<ID3D11DepthStencilView> m_depthStencilView;
    Microsoft::WRL::ComPtr<ID3D11Texture2D>        m_depthStencilBuffer;

    // サンプラープリセット (Init 時に全種生成)
    Microsoft::WRL::ComPtr<ID3D11SamplerState> m_samplers[3];  // WRAP_LINEAR, WRAP_POINT, CLAMP_LINEAR

    uint32_t m_width  = 0;
    uint32_t m_height = 0;
};

} // namespace fbzz::renderer
```

## Submit の処理フロー

`DrawCall` が自己完結しているため、Submit は DrawCall の内容を順に DX11 API に反映するだけ。

```
DX11Renderer::Submit(call)
│
├─ DX11PipelineState → RSSetState / OMSetBlendState / OMSetDepthStencilState
├─ DX11Shader        → VSSetShader / PSSetShader / IASetInputLayout
├─ DX11Buffer        → IASetVertexBuffers / IASetIndexBuffer
├─ constantBuffers[] → VSSetConstantBuffers / PSSetConstantBuffers (スロット 0〜3)
├─ textures[]        → PSSetShaderResources (スロット 0〜7)
└─ DrawIndexed / Draw
```

## DX11ConstantBuffer

```cpp
namespace fbzz::renderer {

class DX11ConstantBuffer : public IConstantBuffer {
public:
    bool Init(ID3D11Device* device, ID3D11DeviceContext* context, size_t sizeBytes);

    void   Update(const void* data, size_t sizeBytes) override;
    size_t GetSize() const override { return m_size; }

    ID3D11Buffer* GetBuffer() const { return m_buffer.Get(); }

private:
    Microsoft::WRL::ComPtr<ID3D11Buffer> m_buffer;
    ID3D11DeviceContext* m_context = nullptr;
    size_t m_size = 0;
};

} // namespace fbzz::renderer
```

`Init` 時に `D3D11_USAGE_DYNAMIC` + `D3D11_CPU_ACCESS_WRITE` で生成し、
`Update` 時は `Map(D3D11_MAP_WRITE_DISCARD)` → `memcpy` → `Unmap` で転送する。

## DX11Shader

```cpp
namespace fbzz::renderer {

class DX11Shader : public IShader {
public:
    bool Init(ID3D11Device* device, ID3D11DeviceContext* context, const std::string& path);

    const std::string& GetPath() const override { return m_path; }

    // DX11Renderer::Submit から呼ぶ
    void Bind(ID3D11DeviceContext* ctx) const;

private:
    Microsoft::WRL::ComPtr<ID3D11VertexShader> m_vs;
    Microsoft::WRL::ComPtr<ID3D11PixelShader>  m_ps;
    Microsoft::WRL::ComPtr<ID3D11InputLayout>  m_inputLayout;

    ID3D11Device*        m_device  = nullptr;
    ID3D11DeviceContext* m_context = nullptr;
    std::string          m_path;
};

} // namespace fbzz::renderer
```

定数バッファ・テクスチャのバインドは `DX11Renderer::Submit()` が担う。`DX11Shader` はシェーダーバイトコードと入力レイアウトの管理のみ行う。

`Init` では `dxc.exe` で事前コンパイルされた `.cso` ファイルをバイナリ読み込みし、`CreateVertexShader` / `CreatePixelShader` に渡す。実行時コンパイル (`D3DCompileFromFile`) は使わない。

## 依存ライブラリ

| ライブラリ | 用途 |
|-----------|------|
| `d3d11.lib` | DX11 デバイス・描画 |
| `dxgi.lib` | スワップチェーン |
| `Microsoft::WRL::ComPtr` | COM オブジェクト RAII 管理 |

`d3dcompiler.lib` / `D3DCompileFromFile` は使わない。シェーダーは `dxc.exe` でビルド時に事前コンパイルし、ランタイムは `.cso` バイトコードをファイル読み込みするだけ。
