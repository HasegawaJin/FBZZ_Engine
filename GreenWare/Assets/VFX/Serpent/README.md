# サーペント (Boss02) 専用エフェクト

`Assets/VFX/Game/` が «盤面の共通語»（極性・弾き・撃破）なのに対して、ここは
**この 1 体の手ごとの絵**だけを置く。共通語の規約（`Game/README.md`）はそのまま
適用される — 特に次の 3 つ。

- **極性の赤青は使わない。** ボスの色は開口の縁・柱・槍と同じ**琥珀**。
  火花・煙・破片は無彩色と熱色のまま（12.2）。
- **画面演出（ScreenEffect / CameraShake / TimeScale）のノードを置かない。**
  配分は `ImpactFeedbackManagerComponent` が持っている。
- **輪は «弾いた» の印、閃光は «壊れた / 斬った» の印。** 1 つの出来事に両方を乗せない。

## なぜ手ごとに分けたか

以前は 10 ある手のうち柱と槍以外が全部 `PlayGroundBlast` ＋ `PlayGroundDust` で、
**叩きつけと締め上げは向きの意味まで含めて同一の絵**だった。唯一の区別だった
「向きで分ける」も、`PlayGroundDust` が渡された向きの y 成分を捨てるせいで
**縦（突き上げ）が表現できておらず、書いてあるのに一度も働いていなかった。**

色を増やせない（赤青は極性専用）以上、読み分けは**シルエット**でしか作れない。

| `.vfx` | シルエット | 鳴る場所 | 逃げる向き |
|---|---|---|---|
| `FX_SRP_Geyser.vfx` | **縦の柱** | 突き上げの着弾 / 胴が口を通っている間 | 穴から離れる |
| `FX_SRP_Slam.vfx` | **帯** | 叩きつけ（弧の 2 つの足元を結ぶ線） | 帯から横へ |
| `FX_SRP_Snap.vfx` | **放射** | 締め上げ（檻の角） | 角から外へ |
| `FX_SRP_Rush.vfx` | **線（点の連なり）** | 走る胴が床を削った点 / 接触ダメージ | 経路から外れる |
| `FX_SRP_Bite.vfx` | **1 点の光 → 着弾** | 噛みつきの溜めと、外した床への突っ込み | 頭の正面から退く |

## 差し替えパラメーター

| グラフ | パラメーター | 用途 |
|---|---|---|
| Geyser | `Rise Speed` / `Width` / `Skirt` | 縦の高さは大きさではなく**速さ**で作る |
| Geyser | `Embers` / `Rim Light` | 縁の琥珀。突き上げと出入りで強さを変える |
| Slam | `Length` / `Scorch Length` | 弧の 2 つの足元の間隔をそのまま入れる |
| Slam | `Width` | **当たり判定（Slam > Radius）と同じ値にすること** |
| Snap | `Outward` / `Cloud Size` | 「寄ってきた」の向きは放射の速さが全部言う |
| Rush | `Wake` / `Spark` | 火花は「速い胴（8 m/s 超）」を絵で言う担当 |
| Bite | `Impact Pose` | false = 喉の溜め / true = 外した着弾。要らない側の層を畳む |

## 枠（プール）の勘定

`VfxManagerComponent` が `.vfx` の種類ごとにリングで回す。ここの 5 本は
鳴る頻度の桁が違うので、枠も別々に持つ。

| 用途 | 枠 | 根拠 |
|---|---|---|
| 噴き上がり（手） | `Geyser Slots` (6) | 突き上げは 1 回に 3 口ぶん撒く |
| 噴き上がり（出入り） | 同上・別タグ | 攻撃の 1 発が出入りの土煙を押し出さないように |
| 走りの削り跡 | `Rush Slots` (20) | 0.12 秒ごと・寿命 1.6 秒 → 「寿命 ÷ 間隔」= 14 が下限 |

**歪み（陽炎）の層はここには 1 つも無い。** 歪むエミッター 1 つにつき全画面コピーが
1 回走るので、「同時に何発出るか」が桁で効く演出には入れない。閃光と陽炎が要るのは
`FX_IMP_Explosion`（折りの芯・撃破の要所）だけで、そちらは発数を絞ってある。
