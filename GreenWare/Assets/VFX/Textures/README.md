# GreenWare VFX テクスチャ素材

企画書 12.2 の色制約に合わせ、**すべての素材は無彩色（輝度のみ）で焼いてある。**
赤（＋）/ 青（－）/ 緑（プレイヤー）はエンジン側でマテリアルから乗算する。
1枚の素材で ＋ と － の両方をまかなえる。

## チャンネル規約

| チャンネル | 中身 |
|---|---|
| RGB | 輝度のみ。グレースケール。色相は持たない |
| A | カバレッジ / 強度（ストレートアルファ、非プリマルチプライ） |

例外は `T_Noise_Seamless` のみ（RGBAそれぞれ別周波数のノイズ）。

## ブレンドの使い分け

12.2 の「全部を加算にすると白飽和して赤と青の区別が消える」に対応するため、
**芯だけ加算・外側はアルファブレンド**で層を分けること。

| 素材 | 推奨ブレンド |
|---|---|
| Glow / Beam / Spark / Arc / Ring / Splash | 加算（Additive） |
| Explosion / Smoke | アルファブレンド（縁）＋ 芯だけ加算で重ねる |
| Crack / Scorch | アルファブレンド（暗くする方向） |
| Sym | アルファブレンド or 加算 |

## 生成スクリプト

すべて手続き生成。再生成すれば別バリエーションが出る。

```
python gen_textures.py                    # 静止テクスチャ13点
MODE=explosion python gen_flip.py         # 爆発FlipFlop
MODE=smoke     python gen_flip.py         # 煙FlipFlop
MODE=explosion SEED=12 python gen_flip.py # 別の乱数で作り直す
MODE=explosion RES=256 python gen_flip.py # 1コマ128pxの軽量版
```

`gen_explosion.py` / `gen_smoke.py` は `gen_flip.py` を呼ぶだけのラッパー。

### FlipFlop の作り（v2）

シルエットが丸くなる問題を、以下の4段で解いている。

| 段 | 内容 |
|---|---|
| ① ローブ分布 | 6方向の「房」に粒子をクラスタさせる。角度を一様に撒くと必ず円になる |
| ② 放射スメア | 密度場を中心から外へ7タップで引き伸ばす。膨張が速い序盤ほど強い。これが触手（テンドリル）になる |
| ③ 3段ノイズ侵食 | 低周波でコブ、中周波で塊、高周波で縁のレース。それぞれ別速度で外へ拡大する |
| ④ 疑似ボリューム陰影 | 密度を光源方向へ6タップ行進させて自己遮蔽を求め、明暗を作る。これがないと平板に見える |

主要パラメーター（`gen_flip.py` 冒頭のモード分岐）:

| 名前 | 意味 |
|---|---|
| `SMEAR0` / `SMEART` | 放射スメアの初期量と減衰時定数 |
| `ABS_S` / `ABS_H` | 煙 / 炎の吸収係数。**上げすぎるとアルファが飽和して板になる** |
| `RAMP` | アルファ立ち上がりの幅。狭いとステッカーのような硬い縁になる |
| `M2G` / `M3G` | 中周波 / 高周波ノイズ侵食の強さ。縁のレース感はここ |
| `RISE` | 上昇量。煙のみ使用 |

## 残っている弱点

- 炎のフィラメント（筋状の火）は出ていない。白熱コアは塊のまま
- 後半の崩れ方が一様。本来は房ごとにバラバラのタイミングで消えるべき
- ループ再生は想定していない（頭と尻がつながらない）

これ以上を求めるなら、EmberGen や Blender Mantaflow で焼いた方が早い。
今のスクリプトは「差し替え可能な素材が即出る」ことを優先している。
