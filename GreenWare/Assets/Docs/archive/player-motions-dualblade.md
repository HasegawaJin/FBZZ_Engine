# プレイヤーのモーション — 双剣

> 親: [企画書](企画書.md) ／ 関連: [双剣](blades.md) [操作・カメラ](camera-controls.md) [演出](presentation.md)
> 出力: `Assets/Models/Player/*.fbx` ／ 書き出し: `GreenWare/Tools/BlenderExport/fbzz_export_minibot.py`

原本は `Player_Model/MiniBot.blend`。30fps、1 アクション = 1 FBX = 1 テイク。
刀を持つクリップは `Katana_` 接頭辞、素手のクリップは接頭辞なし。

刀は `Katana_` 側の全クリップで**両手に持ったまま**。抜刀・納刀だけがソケットを
移動させ、そのタイミングは [アニメーションイベント](#アニメーションイベント) で渡す。

|---|---|:---:|---|

| `Katana_Idle` | 61F / 2.03s | ✅ | 刀を下段に構えた待機。肩を脚と逆位相に 2.5 度振る |
| `Katana_Walk_F/B/L/R` | 33F / 1.10s | ✅ | 歩き。肩の振り 5〜7 度 |
| `Katana_Run_B/L/R` | 25F / 0.83s | ✅ | 走り。肩の振り 8〜10 度 |
| `Katana_Run_F` | 25F / 0.83s | ✅ | **忍者走り。**下記参照 |
| `Katana_FallIdle` | 24F / 0.80s | ✅ | 落下中 |
| `Katana_JumpUp` | 16F / 0.53s | | 踏み切り |
| `Katana_Land` | 20F / 0.67s | | 着地 |
| `Katana_Dodge_Roll` | 17F / 0.567s | | 前転回避。**尺と `dodgeDuration` を一致させること** (下記) |
| `Katana_Run_Stop` | 14F / 0.467s | | 走りからの急停止 |

> **WHY 転がりの尺を回避の秒数と揃えるか (2026-09-05):** ずれていた頃、0.24 秒で
> 4.5m 運びきる一方でクリップは 0.567 秒あったため、踏み切りの姿勢のまま体だけが
> 4.5m 先に居る「瞬間移動」に見えていた。`dodgeDuration` を 0.36 秒へ伸ばし、
> 転がりの再生速度は `PlayerControllerComponent` が毎フレーム
> `dodgeClipSeconds ÷ dodgeDuration` (今は 0.567 / 0.36 = 1.575) から出して
> `SetStateSpeed` で上書きする (2026-09-12)。`.animcontroller` の `speed` は使われない。
> 形は移動の減速に沿わせてある (出だし約 1.36 倍 → 終わり約 0.64 倍。平均は 1 のまま)。

**`Katana_Run_F` だけ他と別物にしてある。**上体を約 28 度前へ倒し
(腰 16 度 + 胸 17 度。胸は `Limit_ROM` で 17.2 度が上限なので、足りない分は腰を倒して
Thigh を逆回転で打ち消し、脚の接地を保っている)、腕は肩を後方へ 26 度伸ばして
体の外側へ開く。刃は下向き 50 度で腰の横に流れる。

> **WHY 前進走りだけ違うか:** 敵へ詰めるのは前進走りだけで、他方向は間合いの
> 微調整に使われる。詰める動作にだけ「踏み込んでいる」姿勢を与えると、
> プレイヤーが今どちらをしているかが姿勢だけで読める。

低い姿勢のクリップ (`JumpUp` / `Land` / `Dodge_Roll`) は、フレームごとに
腕の振り上げ量と肘の曲げを自動探索して切先が床を抜けないようにしてある
(`make_katana_loco_safe`)。最小クリアランスは 0.071 m。

### 攻撃

連撃は左クリックだけで 6 段まで繋がり、段ごとに別のクリップが出る ([双剣](blades.md#連撃))。
左右の対がある段は「押した剣 = 出る絵」、対が無い段は左右共通。

| クリップ | 尺 | 内容 |
|---|---|---|
| `Katana_Slash_R` | 17F / 0.567s | **1 段目 (右)。**右の袈裟斬り。斬り抜け f8 |
| `Katana_Slash_L` | 15F / 0.500s | **1 段目 (左)。**左右対称 |
| `Katana_Double_R` / `_L` | 31F / 1.033s | **2 段目。**左右の刃を続けて振る |
| `Katana_Slash_Return` | 33F / 1.100s | **3 段目。**返し斬り。左右の別が無い |
| `Katana_Slash_Spin` | 21F / 0.700s | **4 段目。**回転斬り。体ごと回るので左右の別が無い |
| `Katana_Slash_Rise` | 19F / 0.633s | **5 段目。**水平回転から軌道を縦へ変える斬り上げ |
| `Katana_SpinRise_R` / `_L` | 33F / 1.100s | **6 段目 (締め)。**回転しながら斬り上げる。連撃で一番大きい動き |
| `Katana_Slash_Dual` | 45F / 1.500s | **溜め斬り。**両刀を**交差させて**斬る。f17 が交差の瞬間 |
| `Katana_Slash_Air` | 16F / 0.533s | 空中斬り。空中で攻撃すると FullBody Slot へ流れる |
| `Katana_Charge_Hold` / `_Release` | 29F / 22F | 通常斬り後も押し続けると Hold をループし、解放時に Release を再生する |
| `Katana_Iai` | 78F / 2.60s | 居合。沈み込んで溜め (f12) → 肩越しに抜き上げ (f18) → 上段へ振りかぶり (f21) → 上から斬り下ろして X 字に振り切る (f25-28) → 残心 (f32-42) → **f48 で `Slash_Dual` と同じ刃の開きを通る** → 納刀 (f60/f65) |
| `Katana_JumpSlam` | 56F / 1.87s | **空中2段目。**空中斬り後の左クリックで叩きつける。着地と同時の f30-34 が命中、通常斬りの2倍ダメージ |
| `Katana_Core_Stab` | 58F / 1.93s | **コアへのフィニッシャー。**中段 (f1) → 腕を前上へ振り上げながら後ろへ体重を乗せる (f6-15) → 前へ踏み込んで突き込む (f19、Root 前 0.30 m) → 押し込む (f24-33) → 引き戻し (f40) → 残心 (f47) → 構えへ。突き切りで手先は体の前 1.27 m・高さ 1.45 m まで出る (コアの高さ帯) |
| `Katana_Parry` | 27F / 0.90s | 受け流し。両刀を交差させて受け (f4-9) → 右から弾き返す (f12) → 残心 (f16-20) → 構えへ |

`Slash_Dual` と `Parry` は左右がぶつかるので、片方を手前・片方を体寄りに
深さをずらした専用ポーズで解いてある (刃どうしの最小距離 0.053 m / 0.076 m)。

`Player.animcontroller` の `Attack` レイヤーは通常6連、溜め、空中2連、居合、
跳躍叩きつけ、コア突きをプリロードする。1〜3段目と溜めは上半身 `Attack` Slot、
腰から回る4〜6段目と、脚まで芝居を持つ空中2連は `FullBody` Slotへ流す。

> **WHY `Slash_Dual` を交差にするか:** 左右対称に振ると必ず正中線で刃が重なる。
> ずらして交差させると、[双剣](blades.md) の「左右を斬り分ける」が
> 1 モーションの中でも絵として出る。

### 登攀 (刀は背中)

| クリップ | 尺 | ループ | 内容 |
|---|---|:---:|---|
| `Climb` | 25F / 0.83s | ✅ | 壁に張り付いて交互に手を掛ける。体を 11 度前傾・頭を 28 度上向き、膝を前へ抱えて足裏を面に当てる。**掛ける手が z 1.98 / 引き付ける手が z 0.98**、どちらも頭より 0.5 m 以上前 |

> **WHY `Katana_` を付けないか:** 登るあいだ刀は**背中**にある。`Katana_` の全クリップは
> 「両手に持ったまま」が前提なので、手が空く登攀はそちら側に置けない。
> 刀の出し入れは既存の `Katana_Sheathe` / `Katana_Draw` が担う。

**登る前に納刀し、甲板に着いたら抜刀する。**engine 側の流れ:

```
脚の根本で入力 → Katana_Sheathe (40F/1.33s、f16→3・f22→4 で刀が背中へ)
              → Climb をループ (登り切るまで)
              → Katana_Draw (34F/1.13s、f16→1・f18→2 で刀が手へ)
              → 甲板で通常の戦闘へ
```

> **WHY 納刀を挟むか:** 両手が塞がったまま登る絵は «刀が壁を貫く» か «手が離れている» の
> どちらかにしかならない。既に抜刀・納刀のイベントがあるので、挟むだけで済む。

### 抜刀・納刀

| クリップ | 尺 | 内容 |
|---|---|---|
| `Katana_Draw` | 34F / 1.13s | 背中の二刀を抜く。右 → 左の順 |
| `Katana_Sheathe` | 40F / 1.33s | 背中へ納める。右 → 左の順 |

> **WHY 左右をずらすか:** 同時に背中へ動かすと二本の刃が背中で交差して貫通する。
> 右を先に納めきってから左を動かすことで、刃の間隔を 41 mm 確保している。

| クリップ | 尺 | ループ | 内容 |
|---|---|:---:|---|
| `Katana_Victory` | 62F / 2.07s | | 刃を払い、両刀を頭上に掲げて静止 → 右 → 左の順に納刀 → 待機へ |
| `Katana_Cheer` | 74F / 2.47s | | 抜刀したまま 3 回跳ねる。頭の横まで腕を上げ、頭上で刃が V 字に交差する。2 回目が最も高く (+0.34 m)、体を ±14 度ひねる |

### 素手 (刀を持たないセット)

`Idle` / `Walk_*` / `Run_*` / `FallIdle` / `JumpUp` / `Land` / `Dodge_Roll` /
`Hit_*` の 19 本。`Katana_` 版の元になっている原地アニメで、
刀を持たない状態が要るときに使う。

`Pose_GripKatana` は指 24 ボーンだけを持つ握りポーズ。
書き出し時の基準ポーズとしても使われる (未キーの指が開いた手にならないようにするため)。

## アニメーションイベント

ノード `FBZZ_EVENT__WeaponAttach` の Position X をステップ信号として読む。静止値は 0。

| 値 | 意味 | 移動先ソケット |
|:--:|---|---|
| 1 | 右の刀を右手へ | `SOCKET_Katana_R` |
| 2 | 左の刀を左手へ | `SOCKET_Katana_L` |
| 3 | 右の刀を背中へ | `SOCKET_BackSword_R` |
| 4 | 左の刀を背中へ | `SOCKET_BackSword_L` |

| クリップ | 発火 |
|---|---|
| `Katana_Draw` | f16 → 1 ／ f18 → 2 |
| `Katana_Iai` | f16 → 1 ／ f19 → 2 ／ f57 → 3 ／ f63 → 4 |
| `Katana_Sheathe` | f16 → 3 ／ f22 → 4 |
| `Katana_Victory` | f36 → 3 ／ f43 → 4 |

上記 4 本以外は値が 0 のまま変化しない = イベント 0 件。
**刀が背中から始まるのは `Katana_Draw` と `Katana_Iai` だけ**で、他はすべて両手から始まる。

> **WHY 手がソケットに着く 3〜5 フレーム手前で切り替えるか:** 握ったまま
> `grab` ポーズまで持っていくと、刃先が反対側の太ももを 14 mm まで貫通する。
> 刃が脚から離れているうちに持ち替えを済ませる。0.1 秒程度なので見た目には出ない。

## リグの向き

| 向き | 世界軸 | 確かめ方 |
|---|---|---|
| 正面 | **-Y** | `Toe_R` の rest 方向が (0, -1.00, -0.07)。`P_VisorDark` の重心も y = -0.24 |
| 上 | +Z | |
| キャラの右 | -X | `UpperArm_R` の head が x = -0.221 |

ポーズ用ボーンのローカル軸は全身で共通に **X+ = 前 / Y = 捻り / Z+ = 下 (腕) ・外 (体幹)**。
`Chest` の X+30 は 30 度の前傾になる。Root の移動は `location[1] = 上` / `location[2] = 前`。

> **WHY ここに書くか:** `Climb` と `Katana_Core_Stab` を最初に作ったとき、正面を +Y と
> 取り違えて全身が前後逆に入った。腕・体幹・踏み込みが揃って «後ろ» を向くので
> 個々のポーズを見ても気づけない。角度を書く前に、この表のどれかで向きを確かめること。

### 可動域 (`Limit_ROM`)

腕・脚・体幹の各ボーンには `LIMIT_ROTATION` コンストレイント `Limit_ROM` が入っていて、
チャンネル値をローカル空間でクランプする。主なもの:

| ボーン | X (前後) | Y (捻り) | Z (上下 / 開き) |
|---|---|---|---|
| `UpperArm_*` | ±90 | ±70 | -95 .. +70 |
| `Forearm_*` | -5 .. +135 | ±80 | ±10 |
| `Hand_*` | ±45 | ±30 | ±60 |
| `Thigh_*` | -35 .. +95 | ±45 | -50 .. +25 |
| `Shin_*` | -135 .. +5 | ±15 | ±8 |
| `Chest` | ±17.2 | ±35 | ±6 |

> **WHY 効いてくるか:** 範囲外の角度を入れても «そうならない»。クランプされた残りが
> 別の軸に化けて、腕が体の後ろへ回る。`Katana_Core_Stab` の振りかぶりを
> `UpperArm` X=170 で書いたのが最初の破綻で、X は ±90 までしか動かない。
> **角度を直接書かず、狙う «向き» を決めて可動域の中から選ぶこと。**

## 検証

モーションを追加・変更したら `katana_verify` (blend 内テキスト) の
`report("<アクション名>")` を回す。全フレームで以下を計測する。

| 項目 | 基準 |
|---|---|
| 刃と頭の距離 | 頭を半径 0.30 m の球で近似し、+0.02 m 以上 |
| 切先の床からの高さ | +0.02 m 以上 (`Katana_JumpSlam` のみ意図的に 0.007 m) |
| 左右の刃の距離 | 0.016 m 以上 (刃厚の合計) |
| つま先の接地 | -0.012 m 以上 |
| 手先が頭より前か | 全フレームで +0.05 m 以上 (登攀・突きは掴む/突く方向が正面) |
| 刃と脚の距離 | 0.095 m 以上 (太もも半径 0.085 + 刃厚 0.008) |

> **WHY 刃と脚を別に測るか:** 頭と床だけ見ていた時期に、納刀中の刃が
> 太ももを 14 mm まで貫通していたのを見落とした。腕は骨、脚は太い
> という非対称があるので、しきい値を分けて持つ。

## 既知の相違

[双剣](blades.md#剣のデザイン方針) は「実在の剣に寄せない短めの直剣、全長 1.2m 前後」
としているが、実際に作ったのは**反りのある刀**で刃長 0.71 m / 全長 1.03 m。
発光色 (右 = 赤 / 左 = 青) は極性の割り当てと一致している。
デザイン方針の記述を実物に合わせて更新するか、刀を直剣へ戻すかは未決。
