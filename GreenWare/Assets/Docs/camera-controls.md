## 操作

| 操作 | アクション |
|---|---|
| 左スティック / WASD | 移動 |
| マウス / 右スティック | カメラ |
| 右入力 | **右剣（＋ / 赤）で斬る** |
| 左入力 | **左剣（－ / 青）で斬る** |
| Space / ボタン | 回避 |
| 中クリック / R3 | ロックオンの切り替え |
| ホイール / 右スティック弾き | ロック対象の変更 |

左右の入力と左右の剣を一致させる。
**入力は2種類の斬撃と回避だけ**という、極めて少ない操作数に収める。

> **WHY 攻撃ボタンが2つあるか:** 一般的な近接アクションは「弱攻撃 / 強攻撃」で
> 2つを使い分ける。本作は**強弱ではなく極**で分ける。どちらを押すかが
> 「相手に何を乗せるか」と「自分がどちらへ飛ぶか」を同時に決めるので、
> 2つのボタンが別々の意味を持つ理由が機械の側にある
> （[blades.md](blades.md#連撃は移動である)）。

### 回避

**純粋な移動アクション。**無敵時間もジャスト回避も持たない。

> **WHY 回避から極性を外したか:** 旧設計は「回避と同時にトリガーを引くと極を纏う」
> という形だった。斬撃そのものが極を帯びる入口になった今、回避にも同じ役を
> 持たせると、極を纏う方法が2つになる。どちらを使えばよいかが場面で変わり、
> 覚えることだけが増える。極を纏うのは剣だけ、と一本に絞る。

## ロックオン

**最寄りの敵を自動で選ぶ。**手動で外すこともできる。

| 項目 | 値 |
|---|---|
| 索敵半径 | 14 m |
| 選び方 | 画面中央に近く、かつ近い相手 |
| 自動解除 | 対象が倒れた / 索敵半径 + 4m の外へ出た |

- ロック中は斬撃と踏み込みがその相手へ向く
- 対象が極を持っていれば、**枠をその極の色で描く**（`AimMarkerComponent`）
- 対象の足元に**反発半径6mの環**を出す（[presentation.md](presentation.md#反発リング)）

> **WHY 照射時代はロックオンを廃していたのに復活させるか:**
> あのときの理由は「線を引く操作にロックオンが割り込むと線が歪む」だった。
> 線を引く操作が無くなったので、この判断は覆る。斬撃は本来「1体を選ぶ」操作で、
> ロックオンはそのための仕組みである。
>
> 近接で自動追尾が無いと、踏み込みのたびに相手を画面中央へ入れ直すことになり、
> 「どちらの剣で斬るか」を考える余地がカメラ操作に食われる。

### ロック中でもカメラは自由に回せる

対象へカメラを固定はしない。**向くのは体と斬撃だけ**で、視点は常にプレイヤーが持つ。

> **WHY 固定しないか:** 本作の判断材料は「盤面の誰と誰が何メートル離れているか」で、
> ロック対象の周りではなく盤面全体にある。カメラを1体へ縛ると、斬っている間
> 他の敵の配置が見えなくなり、次にどちらの剣で斬るかを決められなくなる。

## 視点パラメーター

カメラは**ブーム方式**で組む。固定高さのカメラをその場で回すのではない。

```text
カメラ位置 ＝ ピボット ＋ 回転(yaw, pitch) × (0, 0, −ブーム長)
```

| 項目 | 値 |
|---|---|
| ピボット高（足元から） | 2.90 m |
| ブーム長 | **6.50 m** |
| 中立ピッチ | −12° |
| ピッチ可動域 | −35° 〜 +20° |
| 横オフセット | **0（中央）** |
| 水平FOV | 74°（垂直45.9° / 16:9） |

ピボットを頭頂（2.51m）より少し上の 2.90m に置くことで、
**見下ろし角を変えても自機のスクリーン位置がほとんど動かない。**
固定高さのカメラをその場で回すと、見下ろすほど自機が画面上方へ迫り上がる。
ブームにする理由はこれである。

壁際ではブームを短縮する（外壁高6m / [arena.md](arena.md)）。

### 照射時代から変えた3つ

| 項目 | 旧 | 新 | 理由 |
|---|---|---|---|
| ブーム長 | 5.00 m | **6.50 m** | 近接では自分の周囲6m（反発半径）が判断の範囲。寄りすぎると環が画面に入らない |
| 中立ピッチ | −6° | **−12°** | 地面に敷いた環と敵の足元の距離を読む。水平に近いと床が潰れて距離が測れない |
| ピッチ可動域 | −30° | **−35°** | 同上。真下寄りまで見下ろせると、囲まれたときの配置が読める |

> **WHY 引いた方が近接に向くか:** 直感に反するが、本作で見たいのは
> 「斬っている相手」ではなく「その周りに誰が何極でいるか」。
> 寄せたカメラは打撃を大きく見せる代わりに、判断材料を画面外へ追い出す。

### 横オフセットは0のままにする

左右の剣を対等な記号として設計している以上、片側へ寄せると
**振る剣によって見え方が変わる。**中央に置けば両手が完全に対称になる。

## 廃止したもの

照射（ビーム）を前提にしていた設計は、まるごと不要になった。

| 何 | なぜ |
|---|---|
| クロスヘア（画面中心の上18%） | 狙う1点が無い。代わりにロックオンの枠 |
| 画面上のレーザー長の計算 | 線が無い |
| 銃口位置からの逆算 | 銃が無い |
| エイム9セル（AimYaw / AimPitch / Chest 30度ひねり） | 腕で狙う姿勢が無い |
| 極性回避（Space + トリガー） | 斬撃に統合 |
| 集束時のFOV張り出しの«点火»ぶん | 点火という出来事が無い。集束の張り出しだけ残す |

集束の瞬間だけ画角を広げる（74° → 82°、0.15秒で復帰）のは**残す**。
四方から1点へ飛び込む絵は、通常の画角だと巻き込んだ敵が画面外に出る。

反発では**画角を動かさない。**押しは毎秒使う即時の手で、そこで画角が動くと
連続して押したときに画面が絶えず揺れる。
