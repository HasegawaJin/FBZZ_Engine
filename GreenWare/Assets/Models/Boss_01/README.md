## 1. このフォルダの中身

**基本仕様**

- 30 fps
- 立ち状態で胴体中心 z = 4.50 m、全高およそ 5.8 m
- **足裏の接地面は z = 0.070**（0 ではありません）
- ルートボーンは `Root`（原点・無回転）
- マテリアル23種：**1 オブジェクト = 1 マテリアル**。命名は `M_<オブジェクト名>`（例 `E_ArmorGrey_FR` → `M_E_ArmorGrey_FR`）。

**メッシュ構成 — 脚ごとに分割済み**

`Yaw_*` は車体側のソケットなので脚には含めず `_Body` 側に残しています。

## 2. 一番大事な契約 — 全クリップ「インプレース」

**21クリップすべて root motion = zero**（`net_translation 0.0` / `net_yaw_deg 0.0`、書き出しログで確認済み）。

移動・旋回・ジャンプの放物線は **すべてエンジン側の Root が担当** します。アニメーションが動かすのは Root より下のボーンだけです。

とくに大ジャンプは、跳んでいる間もアニメーション上の胴体高さは一定（ローカル +0.65、ワールド 5.15 m）で固定してあります。`JumpUp` の離陸から `Land` の接地まで縦方向は一切動かないので、**エンジンの放物線とアニメの上下動が二重に足される事故は起きません**。

## 5. クリップ別の意図とイベント時刻

フレームは1始まり。秒はクリップ先頭からの経過（30fps）。

跳ぶための溜めと踏み切り。

| F | 秒 | 何が起きるか |

| 1–18 | 0.00–0.57 | 沈み込み。胴体 4.50 → 3.45 m |
| 18–23 | 0.57–0.73 | 溜め切り。**f23 が最下点（3.38 m）** |
| 23–32 | 0.73–1.03 | 一気に伸び上がる |

| **33** | **1.07** | **4脚同時に足が地面を離れる。ここで上向き初速を与える** |

プレイヤーが見上げて落下点を読む時間なので、必要なだけ回して構いません。

### `Charge_Windup` — 45F / 1.50s / 片道

突進の溜め。胴体が f8 で 4.69 m まで伸び上がり、f38 で 3.83 m まで沈み込みます。**f38 が溜め切り**なので、警告 UI や予兆 VFX はそこに合わせると読みやすくなります。

終端が `Charge_Run` の開始姿勢と一致していないので、0.1 秒程度のブレンドを挟んでください。

### `Charge_Run` — 31F / 1.03s / **ループ（1–30）**

突進中のギャロップ。接地率77%で滞空があります。

| 脚 | 接地 |
|---|---|
| BL | f9 |
| FR | f16 |
| BR | f24 |

前進速度はエンジンが与えます。**足音とアニメがずれないよう、移動速度に合わせて再生速度をスケールしてください。**

### `Magnetic_Pulse` — 60F / 2.00s / 片道

磁力パルス。f24 で胴体 3.76 m まで沈み、f29 で 5.02 m まで跳ね上がります。**パルス発生は f24–29**。両端が Idle 姿勢なのでブレンド不要です。

### `Beam_Start`（30F）/ `Beam_Loop`（31F・ループ1–30）/ `Beam_End`（24F）

ビームの構え → 照射 → 終了。`Start` → `Loop` → `End` の順で繋いでください。`End` の終端は Idle 姿勢です。

### `Beam_Aim` — 31F / **ループ（1–30）**

**上半身5ボーン（Body / Head / Rear / Ring / Core / Muzzle）だけの30カーブ**です。他のクリップに重ねる上書きレイヤーとして使う想定で、単体では脚が動きません。

### `Hit_Add` — 12F / 0.40s

被弾リアクション。**加算（アディティブ）用**です。両端が Idle 姿勢なので、他のクリップの上に足してください。

### `Crash_Stun` — 150F / 5.00s / 片道

突進が壁などに激突して転倒し、5秒間動けなくなる隙。f19–24 で前脚が接地して潰れ、胴体が 3.68 m まで落ちます。終端は Idle 姿勢なので、そのまま `Idle` へ戻せます。

**プレイヤーの最大の反撃チャンス**になる区間です。

### `Death` — 120F / 4.00s / 片道

撃破。f44 で胴体 2.57 m まで崩れ落ちます。終端は崩れたままなので、**最終フレームで停止させてください**（Idle へは戻りません）。

## 7. 既知の癖・注意点

1. **`Land` は接地も衝撃も f22 です。** 脚が伸び切って足裏が z = 0.070 に到達するフレームと、潰れが始まるフレームを同じに揃えてあります。**エンジンは f22 で Root を地面高さに合わせるだけ**で合います。

2. **`Stomp_BR` / `Stomp_BL` は後脚のつま先が地面下 −0.445 m まで刺さります**（前脚は −0.100 m）。フット IK や接地補正を入れる場合はクランプが必要です。

3. **`Stomp_*` は開始・終了姿勢が Idle と 12° 違います。** Idle との間に 0.1 秒程度のブレンドを入れてください。

4. **`Charge_Windup` の終端は `Charge_Run` の開始と一致していません。** ブレンドが必要です。

5. **FBX を Blender に読み戻すとフレーム範囲が `[2, N+1]` になります。** 尺（フレーム数）は正しく、書き出しツールの既存挙動です。他のキャラの FBX も同じなので、取り込み側は既に対応しているはずです。

6. **`Beam_Aim` は上半身だけ**です。単体再生では脚が動きません。

7. 足裏の接地面は **z = 0.070** です。0 で合わせると 7 cm 浮きます。

## 8. 再書き出し手順

1. `Enemy_01/Boss.blend` を開く
2. N パネル →「Boss」タブ →「FBX書き出し」
   （またはテキストエディタで `boss_export_fbx.py` を Run）

**Decimate は書き出し中だけ自動で ON になり、`finally` で必ず OFF に戻ります。** 常時 ON にするとビューポートが 134 ms/frame（OFF 時 1.3 ms/frame、103倍）まで落ちるので、作業中は OFF のままにしてください。この状態でも書き出しには正しく減面が乗ります。

書き出しには1クリップ 40〜250 秒、全部で 40 分ほどかかります。FBZZEditor を閉じてから走らせると速くなります（フォルダ監視と `.meta` 生成が競合しているようです）。

アクションを1本ずつ別ファイルに書き出す作りです。**36アクションを一括ベイク（`bake_anim_use_all_actions=True`）すると Blender が落ちます。**
