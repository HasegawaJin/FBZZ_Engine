# GreenWare SFX — v3（双剣化 / アリーナ実寸 対応）

48kHz / 16bit / モノラル WAV。すべて手続き的合成（録音素材は不使用）。
`Assets/Sound/SE/<カテゴリ>/` に、これまでと同じ並びで入る。

---

## 1. アリーナの反射を実寸に張り直した（Boss 35点すべて差し替え）

これまでのボスSEは**半径28mのアリーナ**を前提に、163ms 後に最初の壁反射が返るよう作ってあった。
`arena.md` の現行値で組み直した。

| | 距離 | 返る時刻 |
|---|---|---|
| 屋根の輪（内半径17.3m / 高さ6m） | 2√(17.3²+6²) = 36.6 m | **107 ms** ← 最初はここ |
| 外壁（床の縁 40m） | 80 m | **233 ms** ← 部屋の広さはこれで決まる |

**107ms まで何も返らない間**が、この場所の広さそのものになっている。
実測（無音に一撃を置いて測ったもの）：

```text
中央（青天井）  104 / 116 / 128 / 152 / 168 / 232 / 268 ms
屋根の下        104 / 116 / 128 / 152 / 168 / 188 / 200 ms
```

**中央は屋根が抜けているので、後部残響が短く暗い**（`arena(open_sky=True)`）。
外周寄りは屋根の下に入るので長い。ボスは中央に立つので中央設定で書き出してある。
関数は `sfxlib.arena()` に移してあるので、他のカテゴリからも同じ部屋が呼べる。

## 2. 双剣のSE（新規 30点）— 銃の27点を置き換え

`SE_WPN_*` は照射・なぞり・バッテリー・タップの音で、`blades.md` で全部廃止された。
プレフィクスを **`SE_BLD_`**（Blade）に変えて、フォルダは `Weapon/` のまま。

### 音程の置き方

| | 基音 | 性格 |
|---|---|---|
| ボス | 55 Hz | 一番下 |
| 旧・銃 | 110 / 330 Hz | （廃止） |
| **右剣 ＋（赤）** | **220 Hz** | 低く太い |
| **左剣 −（青）** | **660 Hz** | 高く鋭い |

同じA系の3オクターブに分けてあるので、剣とボスが同時に鳴っても濁らない。
実測のスペクトル重心で、＋と−は **1.3〜2.8倍**に分かれている。

### ファイル

| ファイル | 数 | 内容 |
|---|---|---|
| `SE_BLD_Swing_{R,L}_{1st,2nd,3rd}_NN` | 12 | 空振り。**3段目だけ長く太い**（発生と硬直が長い段） |
| `SE_BLD_Hit_{R,L}_NN` | 6 | 命中。接触＋装甲の鳴り＋**極が乗る音** |
| `SE_BLD_Hit_Finish_{R,L}` | 2 | 3段目の命中。「止めた」が手に返る |
| `SE_BLD_Charge_{Plus,Minus}` | 2 | **振っている0.9秒だけ自分がその極を帯びる。**下に敷き続ける |
| `SE_BLD_Neutralize_NN` | 2 | 逆極を斬って中和。上がる要素を入れていない |
| `SE_BLD_ChargeUp_Loop` | 1 | 溜め中のループ。**24Hz のAM**（`shakeHz` と同じ）を入れてある |
| `SE_BLD_ChargeUp_Full` | 1 | `chargeTime` 0.75秒の満溜め |
| `SE_BLD_ChargeSlash_{R,L}` | 2 | 溜め斬り。**全周を薙ぐ**ので左右に抜けず、環が走る |
| `SE_BLD_Dash_NN` | 2 | 踏み込み。`approachStopGap` で**ちょうど止まる**音を末尾に入れてある |

**斬撃は相手を飛ばさない**（`blades.md`）ので、命中音は重い衝撃ではなく
「極が乗った」ことを返す音にしてある。飛ばす音は極性側（`SE_ATR_*` / `SE_POL_Repulse_*`）に置いた。

### 鳴らし方

- 連撃は `1st → 2nd → 3rd`。3段目は `Hit_Finish` に差し替える
- **振り始めと同時に `SE_BLD_Charge_{Plus,Minus}` を重ねる。**0.9秒でちょうど切れるので、
  無極へ戻ったことも音で分かる
- 発生は 0.08秒。`Swing` を鳴らしてから 0.08秒後に `Hit`
- 同じ剣を続けたときは `SE_POL_Push_Self`、斬り分けたときは `SE_POL_Pull_Self` を重ねる。
  **これが「連撃＝移動」の音の実体**になる
- 溜めは `ChargeUp_Loop` を鳴らしながら、溜め比の2乗で音量とピッチを上げる。
  満溜めで `ChargeUp_Full`、離したら `ChargeSlash`

## 3. 押しと引きを別の音にした（新規 9点）

`presentation.md` の「押しと引きは、演出でも別物にする」をそのまま音に落とした。

| ファイル | 数 | 内容 |
|---|---|---|
| `SE_POL_Repulse_NN` | 4 | 反発の「バンッ」。**高め・乾いた・短い**（0.30秒） |
| `SE_POL_Pull_Self` | 1 | 自分が引かれる。溜め0.45秒 →「ギュン」と加速 |
| `SE_POL_Push_Self` | 1 | 自分が弾かれる |
| `SE_IMP_PushKill_NN` | 3 | **押し込み撃破。**集束撃破（`SE_IMP_Final`）とは別の語彙 |

**`SE_POL_Repulse_*` にはアリーナの反射を掛けていない。**
毎秒出る音なので、残響が積み重なると盤面が読めなくなる
（`presentation.md`「画面に残らないことが要件」を音にも適用した）。

**反発は1回につき1回だけ鳴らす。**反発は必ず2体に効くので、
体ごとに鳴らすと「バンッ」が毎回2重になる（`ApplyRepulsion` で1回）。

押し込み撃破は数を数えない。`×5 CHAIN` と違い、**1体ごとに短く強い音**を返す。
末尾に短い確定音（1174→1568Hz）を入れて、集束の音と混ざらないようにしてある。
