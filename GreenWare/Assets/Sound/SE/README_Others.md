## 1. Player の足音を作り直した

### 何が問題だったか
旧版はピッチだけを振っていたので、単発では自然でも**続けて鳴らすと同じ音の繰り返し**に聞こえた。
足音は「一撃」ではないので、変えるべきはピッチではなく**接地の構造そのもの**だった。

### 1歩の中身（6層）

| | 内容 |
|---|---|
| ① | 接地直前、脚のサーボが減速する（12ms 先行） |
| ② | **かかと** — 硬く短い接触 |
| ③ | **足裏が遅れて当たる** — 走り 18〜46ms / 歩き 30〜62ms 後 |
| ④ | 床（アリーナのパネル）が 96〜148Hz で鳴る |
| ⑤ | 擦れ — 走り42% / 歩き30% の確率でだけ鳴る |
| ⑥ | 脚の部品が収まる細かいガタつき |

さらに 28% の確率で **3段目**（足が転がる接地）が入る。

### バリエーションの作り方
乱数任せにすると偶然そっくりな2つが生まれ、それが連続したとき破綻する。
そこで全パラメータを**層化**した（範囲を変種数で等分して1つずつ配り、割り当て順だけを振る）。

検証結果：

| | 波形相関 平均 | 最大 | 音量幅 | 減衰時間の幅 |
|---|---|---|---|---|
| Run（8変種） | 0.10 | 0.51 | 3.8 dB | 29 ms |
| Walk（6変種） | 0.11 | 0.39 | 3.9 dB | 14 ms |

相関 1.00 が同一。**0.5 未満なら別々の接地に聞こえる。**

**1歩ごとの音量差（−2.4〜+1.8dB）はファイルに焼き込んである。**
エンジン側で音量を揃えないこと。揃えると機械の足音に戻る。

### 鳴らし方
- 走り 0.355秒間隔 / 歩き 0.58秒間隔。**±3% ほど間隔を揺らす**（人の歩容は等間隔にならない）
- 直前2つと同じ番号を引かないシャッフルで選ぶ
- 確認用：`_Demo/SE_DEMO_06_Gait.wav`（走り16歩 → 歩き10歩）

## 2. Boss の音を企画書のフレーム表に合わせて作り直した（35ファイル）

すべて **30fps のフレーム番号**にそのまま乗る長さで書き出してある。
アリーナは**半径28m**なので、往復56m ÷ 343m/s = **163ms 後に最初の壁反射**が返る。
ボスの音は全部この反射を通してあり、これが「広い場所にいる」の正体になっている。

### 音程の置き方
ボスは **55Hz（A1）系**。プレイヤーの銃は 110Hz（＋）/ 330Hz（−）なので、
**ちょうど1オクターブ下**に逃がしてある。同時に鳴っても濁らない。

| | スペクトル重心 |
|---|---|
| ボスのコアビーム | 1062 Hz |
| プレイヤーの銃（＋） | 1961 Hz |
| プレイヤーの銃（−） | 4288 Hz |

### 巡回 / 移動

| ファイル | 長さ | 内容 |
|---|---|---|
| `SE_BOSS_Step_Walk_01〜04` | 1.25s | 巡回クロール（2.4m/s・40F周期）。4本を順に運ぶので4変種 |
| `SE_BOSS_Step_Charge_01〜04` | 1.00s | 突進クロール（5.0m/s・30F周期） |
| `SE_BOSS_Servo_Loop` | 2.00s | **ループ。**常時鳴らす土台。停止中は 0.4〜0.5 で敷く |

### 突進 → 激突（企画書 45F / 20Fループ）

| ファイル | フレーム | 内容 |
|---|---|---|
| `SE_BOSS_Charge_Windup` | F1–45 | F1-8 逆モーション / F8-26 沈み込み / F26-45 保持（0.1秒周期の微振動） |

### 踏みつけ（企画書 60F の表そのまま）

| ファイル | フレーム | 内容 |
|---|---|---|
| `SE_BOSS_Stomp_Raise_01/02` | F4–16 | 予備動作。**F16で音が切れる** |
| （無音） | F16–20 | **完全静止 0.13秒。ここが予兆。**何も鳴らさないこと |
| `SE_BOSS_Stomp_Impact_01/02` | F23 | 着弾。胴体0.58m沈下＋足先0.30m貫入 |

検証：F16-20 は −32.9dB（実質無音）、F4-16 は −19.0dB、F23 の着弾は **−5.6dB**。
予備動作より着弾が 13dB 大きい。ここが逆転すると打撃感が消える。

### 極性切替と磁力パルス

| ファイル | 長さ | 内容 |
|---|---|---|
| `SE_BOSS_PolSwitch_Warn` | 1.00s | 明滅が加速して最後はトリルになる。**終端が切替の瞬間**に合う |
| `SE_BOSS_PolSwitch_01` | 1.15s | → ＋（低く重い） |
| `SE_BOSS_PolSwitch_02` | 1.15s | → −（高く鋭い） |

鳴らし方：**切替の 1.0 秒前に Warn を出す** → 切替の瞬間に PolSwitch → その 20ms 後に MagPulse。
P1 は6秒周期、P2 は4秒周期。

### コアビーム

| ファイル | 長さ | 内容 |
|---|---|---|
| `SE_BOSS_Beam_Charge` | 1.40s | アパーチャの絞りが開く → 充電 → 最後にアークが飛ぶ |

| `SE_BOSS_Beam_Sweep` | 1.90s | 旋回して薙ぐ層。**Loop に重ねる。**床の継ぎ目を横切るたびに床が鳴る |

2回薙ぐなら再生速度を 1.1 倍ほど変えて重ねると同じ音に聞こえない。

Appear の脚は同時に落とさないこと。同時だと1本足に聞こえる。

## 3. 全ファイルに効いた修正（Boss / Player 以外も再生成済み）

合成ライブラリ側に3つバグがあり、**すべての音のトランジェントが潰れていた。**

1. **残響のインパルス応答をピーク正規化していた** — 畳み込みで +20dB 以上跳ね上がり、
   mix パラメータが意味を成していなかった。エネルギー正規化に変更。
2. **飽和処理が入力 |x|≤1 を前提にしていた** — 実際には数倍入っていたので波形が矩形に潰れ、
   打撃音の立ち上がりが消えていた。飽和の前にピークを揃えるよう変更。
3. **瓦礫のガラガラが粒の重なりで青天井になっていた** — 呼び出し側の係数が効いていなかった。

結果（クレストファクタ＝ピークとRMSの差。打撃音は12dB以上ほしい）：

| フォルダ | 修正前 | 修正後 |
|---|---|---|
| Impact | 7.6 dB | **13.0 dB** |
| Player | 11.9 dB | **16.0 dB** |
| Weapon | 12.7 dB | 14.0 dB |
| Enemy | 10.7 dB | 13.3 dB |
| UI | 11.7 dB | 13.1 dB |

**特に Impact（衝突音）が別物になっているので、旧版と差し替えて確認してほしい。**
